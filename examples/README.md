# 예제 안무

처음 켠 사람이 결과물부터 볼 수 있게 두는 **저장 포맷 그대로의 안무표**다(로드맵 RM-26). 앱의 빈 안무표 안내에 있는 `예제 열기` 가 이 폴더의 파일을 `fetch` 로 읽어, 최근 목록에서 여는 길과 같은 길로 연다. 서버(`server.py`)가 없는 정적 호스팅에서도 열린다.

- `shim-sham.json` — Shim Sham 8마디(Shim Sham ×3 · Break · Push & Cross-over ×3 · Break). 공개 유튜브 링크와 기준 박자(172 BPM)가 들어 있다. 영상이 내려가면 격자만 보인다.

파일은 `프로젝트 저장` 이 쓰는 모양과 같다 — `tests/unit/exampleChoreo.test.mjs` 가 저장 포맷 검사를 통과하는지와 8마디 · 영상 링크 · 박자를 가졌는지 잰다.
