# 지원 범위 — OS × 브라우저 × 서버

이 앱은 **어떤 브라우저로 여느냐**와 **로컬 서버(`python3 server.py`)를 켰느냐**에 따라 되는 기능이 다르다. 안 되는 것은 고장이 아니라 그 환경에 조건이 없는 것이다. 어느 환경에서 무엇이 되는지를 한 표에 모았다(로드맵 RM-27).

지금 이 브라우저에서 실제로 무엇이 되는지는 `⚙ 설정` 의 `이 환경` 갈래가 **탐지해서** 보여 준다 — 아래 표의 OS · 브라우저 칸은 알려진 결과이고, 실제 판정은 브라우저가 그 기능을 가졌는지로만 한다(이름 · 사용자 에이전트 문자열로 가르지 않는다). 켤 때 안 되는 것이 있으면 토스트로 한 번 알리고, 환경이 바뀐 때만 다시 뜬다. 끄려면 `이 환경` 의 `안 되는 것 알림: 켬` 을 누른다.

## 표 읽는 법

- `○` 된다 · `△` 되지만 제약이 있다(느리거나 일부만) · `✕` 안 된다.
- **필요한 것** 열의 조건은 둘로 나뉜다. **서버 쪽**(서버 · ffmpeg · 모델 파일)은 어느 브라우저든 같고 서버를 어떻게 켰느냐에 달렸다. **브라우저 쪽**(폴더 고르기 · 음성 인식 · GPU)은 브라우저마다 다르다.
- 서버가 없으면 서버 쪽 조건은 「서버 없음」 하나로 묶인다 — 정적 호스팅에서는 ffmpeg 이 있고 없고를 따질 자리가 없다.
- GPU 는 자세 분석 모델을 한 번 띄워 봐야 안다. 그 전까지 `이 환경` 은 그 행을 「아직 모름」으로 둔다.

## 행마다 한 줄

- **안무표 편집 · 저장 · 되살리기** — 격자에 놓기 · 루틴 · 되돌리기 · 작업 중 문서 담기(브라우저 저장소). 아무 조건이 없다.
- **영상 보관 — 서버 방식** — 고른 영상을 서버가 데이터 폴더의 `video-clip/<프로젝트>/` 에 복사하고 스트리밍한다. 폰에서도 된다.
- **영상 보관 — 브라우저 폴더 방식** — 서버가 없을 때의 길. 폴더 고르기 API(`showDirectoryPicker` + IndexedDB)는 데스크톱 크롬 · 엣지에만 있다. 없는 브라우저에서는 영상을 열 수는 있지만 다음에 같은 파일을 다시 골라야 한다.
- **안무표 폴더 보관** — 저장할 때 `<서버 루트>/projects/` 에도 쓴다. 서버가 없으면 내려받기만 된다.
- **영상 자르기 · 내보내기** — 서버가 ffmpeg 을 자식 프로세스로 돌린다. 서버에 ffmpeg 이 없으면 그 기능만 꺼지고 버튼의 안내 줄이 말한다.
- **자세 분석** — 모델 파일은 서버가 받아 두고 계산은 브라우저가 한다. 크롬 계열 밖에서는 GPU 로 서지 못해 느릴 수 있다(△).
- **자세 분석 GPU 가속** — WebGL 이 막히면 조용히 CPU 로 떨어진다. 실측으로 약 6배 느리다. 어느 쪽으로 섰는지는 자세 분석 패널과 `이 환경` 에 적힌다.
- **말로 이름 붙이기 · 말하기** — Web Speech API. 크롬은 음성을 구글 서버로 보내 인식한다(끌 수 없다). 사파리는 API 가 있지만 중간 결과가 드물어 △, 파이어폭스는 없다.
- **말로 채우기 — LLM** — LLM 은 서버가 부르고 키는 서버에만 있다. 🎤 `말하기` 단추는 음성 인식 행을 따른다.

## 이 표가 바뀔 때

- 설치형 앱(로드맵 RM-28)이 오면 열이 하나 는다.
- 정적 호스팅의 저장을 IndexedDB 로 옮기면(RM-33) 「영상 보관 — 브라우저 폴더 방식」 행이 바뀐다.
- 행 · 열을 더할 때는 코드 표(`FEATURES` · `ENVIRONMENTS`)에 먼저 더하고 이 문서의 표를 다시 옮긴다. 시험이 어긋남을 잡는다.
