# 튜토리얼

이 도구를 처음 켜는 사람을 위한 문서다. 서버를 띄우는 것부터 8마디짜리 안무 한 곡을 만들어 파일로 받는 것까지, 손이 가는 순서대로만 적었다. 버튼 하나가 정확히 무슨 일을 하는지 찾을 때는 [기능 설명서](FEATURES.md)를, 이 도구가 무엇이고 왜 이렇게 생겼는지는 [프로젝트 소개](../README.md)를 본다.

## 준비물

- 저장소를 내려받은 폴더
- `python3` — macOS 와 리눅스에는 대개 이미 있다. `python3 --version` 으로 확인한다
- 최신 브라우저 하나

설치할 것은 없다. Node 도 npm 도 빌드도 필요 없다.

## 첫 실행

### 서버를 켠다

터미널에서 저장소 폴더로 이동해 다음을 친다.

```
python3 -m http.server 8000
```

터미널을 그대로 둔 채 브라우저에서 `http://localhost:8000` 을 연다. 왼쪽에 `안무 편집기` 라는 제목과 `안무표, 카테고리, 동작을 한 번에 관리` 라는 한 줄이, 오른쪽에 `8x8 안무 테이블` 이 보이면 제대로 뜬 것이다.

터미널을 닫으면 서버도 꺼진다. 작업하는 동안은 열어 둔다.

### `index.html` 을 더블클릭하면 왜 안 되나

더블클릭은 주소가 `file://` 로 열리고, 그러면 브라우저가 ES 모듈 로딩과 문서 `fetch` 를 둘 다 막아 화면이 빈 채로 멈춘다. 반드시 위의 서버를 거쳐 `http://localhost:8000` 으로 연다.

## 화면 읽기

### 왼쪽 사이드바

위에서 아래로 다섯 덩어리다.

- `프로젝트 저장 / 불러오기` — 안무를 JSON 파일로 내보내고 되받는다. 그 아래 목록은 이 브라우저에 남은 최근 프로젝트 10개이고 `최근순` `이름순` 으로 정렬을 바꾼다.
- `동작 저장 / 불러오기` 와 `카테고리 저장 / 불러오기` — 동작 목록만, 카테고리만 따로 주고받을 때 쓴다. 각각 최근 3개까지 기억한다.
- `루틴 목록` — 되풀이되는 동작 묶음을 모아 둔다. 처음에는 `아직 루틴이 없습니다. + 새 루틴을 눌러 만들어 보세요.` 만 적혀 있다.
- `카테고리 관리` — 갈래마다 색 네모, 이름 칸, `★`, `×` 가 한 줄이다. 처음에는 `step` `turn` `jump` `rotate` `shimmy` `fall` 여섯이다.
- `솔로 동작 추가` 와 `동작 목록` — 위 칸(`예: Shorty George`)에 이름을 적고 갈래를 골라 `추가` 하면 아래 `동작 목록` 에 카드로 쌓인다. 처음부터 `Jazz Square` `Suzie Q` `Charleston` `Pivot Turn` `Air Step` `Shimmy` `Fall Off Log` `Spin Out` `Tacky Annie` `Boogie Back` 열 개가 들어 있다.

`동작 목록` 위의 `동작 검색...` 칸으로 걸러 보고, `가나다` `추가순` `카테고리` 로 순서를 바꾸며, 그 옆 화살표 버튼이 오름/내림을 뒤집는다.

### 오른쪽 안무표

머리줄은 `마디`, 1부터 8까지의 숫자, `비고` 세 칸으로 나뉜다.

행 라벨은 위에서부터 `intro`, `8x1`, `8x2` … 다. **한 행이 8카운트 한 마디**이고 한 칸이 1카운트다. `8x2` 는 "8카운트짜리 두 번째 마디"라는 뜻이다. 앞의 `8` 은 한 마디의 카운트 수다. 메인 안무표에서는 이 값을 화면에서 바꿀 수 없어 늘 8이고(다른 값으로 저장된 파일을 불러오면 그때만 달라진다), 루틴 편집기에서만 `박자` 로 바꾼다. `intro` 는 마디로 세지 않는 도입부 자리이고 메인 안무표에만 있다.

`비고` 칸에는 그 행에서 **시작하는** 동작이 `Jazz Square (8x1 : 1 [4])` 꼴로 적힌다. 괄호 안은 "시작한 행 : 시작 카운트 [전체 카운트]" 다. 두 행에 걸친 동작도 시작한 행에만 한 번 적힌다. 루틴 블록은 `▶ 루틴 1` 처럼 삼각형이 붙는다.

머리 위 도구줄에는 `안무표 크기`, `기본 카운트`, `+ 빠른 배치`, `▶ 영상 패널`, `Undo`, `Redo`, `전체 초기화(링크 포함)` 이 있다. `안무표 크기` 의 `8 x` 뒤 숫자가 **마디 수**이고, `기본 카운트` 는 새로 놓는 블록의 기본 길이다. `▶ 영상 패널` 은 켜야 보이는 것이라, 누르기 전까지 화면은 지금 그대로다.

## 8마디 안무 한 곡 만들기

여기서부터는 하나의 목표를 끝까지 따라간다. `8x1` 부터 `8x8` 까지 여덟 마디를 채우고, 참고 영상과 박자를 맞춘 뒤, 그것을 JSON 파일 하나로 받는 것이 끝이다.

### 1단계 — 마디 수를 확인한다

`안무표 크기` 의 `8 x` 뒤 숫자를 본다. 처음 켜면 8이므로 그대로 두면 된다. `−` `+` 버튼이나 숫자 칸으로 1에서 128까지 바꿀 수 있다.

숫자를 **줄이면 그 아래 마디에 있던 블록이 지워진다.** 실수로 줄였다면 `Undo` 로 되돌린다.

### 2단계 — 첫 동작을 끌어다 놓는다

`동작 목록` 에서 `Jazz Square` 카드를 잡아 `8x1` 행의 첫 칸에 떨어뜨린다. 끄는 동안 놓일 자리에 미리보기가 뜬다. 손을 놓으면 `Jazz Square 1c` 라고 적힌 블록이 생긴다. 이 길이는 도구줄 `기본 카운트` 값(처음에는 1)을 그대로 따른다.

### 3단계 — 길이를 늘리고 자리를 옮긴다

블록 안에는 손잡이가 둘 있다. 왼쪽 끝이 `위치 이동`, 오른쪽 끝이 `길이 조절` 이다.

- 오른쪽 손잡이를 잡아 오른쪽으로 끌면 길이가 늘어난다. 4칸까지 끌면 라벨이 `Jazz Square 4c` 로 바뀐다. 마디 끝을 넘어가면 다음 행으로 이어진다. 늘린 자리에 이미 동작이 있으면 지우지 않고 그 아래 층으로 들어간다 — 옮기기와 같은 규칙이다.
- 왼쪽 손잡이를 잡아 끌면 블록이 통째로 옮겨진다. 옮긴 자리에 이미 동작이 있으면 지우지 않고 그 아래 층으로 들어간다.
- **Alt 를 누른 채** 왼쪽 손잡이를 끌면 원본을 남기고 복사본이 놓인다. Alt 는 **끌기를 시작하는 그 순간**에만 읽는다. 끌다가 중간에 눌러도 복사가 되지 않으니, 누른 다음에 잡아야 한다.
- 블록을 **더블클릭하면 지워진다.** 확인을 묻지 않는다.

### 4단계 — 나머지 마디를 빠른 배치로 채운다

도구줄의 `+ 빠른 배치` 를 누른다. 버튼이 켜진 상태가 되면 격자를 직접 쓸어 길이를 정할 수 있다.

`8x2` 행의 빈 자리를 누른 채 오른쪽으로 쓸면 쓴 만큼 미리보기가 늘어난다. 손을 떼는 순간 `동작 선택` 팝업이 뜬다. `동작 이름 검색...` 에 몇 글자를 치고 목록에서 고르면 **쓸어 둔 길이 그대로** 놓인다. 쓸지 않고 한 번만 누르면 `기본 카운트` 만큼 놓인다.

팝업은 키보드로도 다룬다. `↓` `↑` 로 항목을 옮기고 `Enter` 로 고르며 `Esc` 로 닫는다. 다만 **화살표로 명시해 고르기 전의 `Enter` 는 "새 동작 추가"로 넘어간다** — 검색 결과가 보인다고 해서 첫 항목이 골라지지 않는다.

### 5단계 — 없는 동작을 그 자리에서 만든다

`동작 선택` 에서 목록에 없는 이름을 치면 검색 칸 옆의 초록 `+` 가 켜지고 `"…" 와 일치하는 동작이 없습니다. Enter를 눌러 새 동작으로 추가` 라는 안내가 뜬다. `+` 를 누르거나 `Enter` 를 치면 카테고리 화면으로 넘어간다.

카테고리 화면에서는 `카테고리 검색...` 으로 갈래를 찾아 고르면 동작이 만들어지면서 바로 놓인다. 없는 갈래를 새로 만들려면 초록 `+` 를 눌러 입력 칸을 펼치고 `✦ 추가 & 배치` 를 누른다.

`카테고리 관리` 에는 갈래를 새로 만드는 버튼이 **없다.** 새 갈래는 이 화면에서, 또는 `카테고리 열기` 로 파일을 불러와서만 생긴다.

### 6단계 — 손과 발을 겹쳐 쌓는다

같은 카운트에 두 가지를 동시에 적고 싶을 때가 있다. 이미 블록이 있는 칸에 다른 동작을 끌어다 놓거나 빠른 배치로 놓으면 **지우지 않고 아래층으로 쌓인다.** 그 행의 높이가 늘고 층 사이에 구분선이 생긴다.

어떤 방법으로 겹쳐도 결과는 같다. 외울 것이 없다.

| 겹치는 방법 | 그 자리에 있던 동작 | 겹친 쪽 |
|---|---|---|
| `동작 목록` 카드를 끌어다 겹친 자리에 놓기 | 남는다 | 새 동작이 **아래층**으로 들어간다 |
| `+ 빠른 배치` 로 겹친 자리를 쓸어 놓기 | 남는다 | 새 동작이 **아래층**으로 들어간다 |
| 왼쪽 손잡이로 블록을 끌어 겹친 자리에 옮기기 | 남는다 | 옮긴 블록이 빈 층을 찾아 들어간다 |
| 오른쪽 손잡이로 늘려서 남의 자리를 덮기 | 남는다 | 늘린 블록이 빈 층을 찾아 들어간다 |

넷 다 지우지 않으므로 확인을 묻지 않는다. 2026-09-07 이전에는 마지막 줄만 규칙이 달라 **늘려서 덮은 동작이 묻지도 않고 사라졌는데**, 이제 넷이 같다. 겹쳐 두는 것이 목적이라면 늘려서 덮어도 되고 새로 놓아도 된다.

여러 행에 걸친 블록을 늘렸다면 그룹 전체가 함께 내려간다 — 한 행에서만 겹쳤어도 다른 행의 조각까지 같은 층으로 옮겨진다. 한 블록은 어느 행에서나 같은 층에 있어야 하기 때문이다.

### 7단계 — 되풀이되는 묶음을 루틴으로 만든다

같은 여덟 카운트가 곡 안에서 세 번 나온다면, 그 묶음에 이름을 붙여 두고 블록 하나로 놓는 편이 낫다. 만드는 길이 둘이다.

**안무표에서 골라 만들기.** 이미 놓은 블록을 하나씩 클릭하면 테두리가 켜지며 선택된다. 하나 이상 고르면 도구줄에 `루틴으로 편성 (3)` 처럼 개수가 붙은 버튼이 나타난다. 누르면 `루틴 1` 이라는 이름의 루틴이 만들어지고 루틴 편집기가 열린다. 고른 블록은 안무표에 그대로 남는다.

**빈 루틴부터 만들기.** `루틴 목록` 의 `+ 새 루틴` 을 누르면 `8박자 × 4행` 짜리 빈 루틴이 생기고 편집기가 열린다. 편집기 안의 격자는 메인 안무표와 똑같이 다룬다 — `+ 빠른 배치` 도 그대로 있다. 크기는 `박자` 와 `행` 으로 정하고, `초기화` 는 그 루틴 격자만 비우며, `✕ 닫기` 로 빠져나온다. 편집기 안의 `Undo` `Redo` 는 메인 안무표와 별개로 이 루틴의 이력만 오간다.

만든 루틴 카드는 `루틴 목록` 에 색 칩과 함께 `8박자 × 4행` 이라고 적혀 나온다. 루틴마다 색이 순서대로 다르게 붙고, 안무표에 놓인 루틴 블록도 그 색으로 그려진다 — 카드의 칩 색을 보면 보드의 어느 블록이 그 루틴인지 알 수 있다. 카드의 `★` 는 즐겨찾기, `✏` 는 편집, `×` 는 삭제이고, 이름을 더블클릭하면 `루틴 이름` 을 묻는 창이 뜬다.

**카드를 안무표에 끌어다 놓으면 블록 하나가 된다.** 이때 차지하는 길이는 `박자 × 행` 이다 — `8박자 × 4행` 짜리 루틴은 **4마디를 통째로** 먹는다. 안을 다 채우지 않았어도 자리는 그만큼 차지하니, 8마디 곡에 넣을 생각이라면 편집기에서 `행` 을 먼저 줄여 둔다.

안무표에 놓인 루틴 블록은 한 번 클릭하면 `✏ 편집` / `× 삭제` 팝업이 뜬다. 일반 블록과 달리 길이 조절 손잡이가 없고 더블클릭으로 지워지지도 않는다.

### 8단계 — 참고 영상을 붙인다

안무표 바로 위 `▶ YouTube` 줄의 `YouTube URL 입력...` 에 주소를 붙여 넣는다. 타이핑이 멎고 **700ms** 뒤에 영상 제목을 조회하며, 그동안 `제목 불러오는 중…` 이 옆에 뜬다. 조회에 성공하면 제목이 칩으로 붙고, `↗` 버튼으로 새 창에서 연다. 인터넷이 없으면 제목만 비고 주소는 그대로 남는다. 각 줄 끝의 `✕` 는 그 줄만 비운다.

`☑ ClickUp` 줄도 같은 방식이다. `+ 링크 추가` 를 누르면 `레이블` 과 `URL 입력...` 한 쌍이 늘어난다.

### 9단계 — 영상을 옆에 띄우고 박자를 맞춘다

주소를 넣었으면 안무표 도구 모음의 `▶ 영상 패널` 을 누른다. 오른쪽에 영상이 뜨고 안무표가 그만큼 좁아진다. **주소를 방금 넣은 그 칸이 그대로 소스다** — 패널 안에 주소를 또 넣을 곳은 없다.

유튜브가 아니라 내 컴퓨터의 촬영본을 쓰고 싶으면 영상 화면 아래 `📁 영상 파일 열기` 를 누르고 파일을 고른다. 파일이 유튜브 주소보다 우선하고, `✕ 파일 놓기` 를 누르면 다시 유튜브로 돌아간다. 브라우저는 파일 위치를 기억하지 못하므로 저장한 안무표를 다음에 열면 같은 파일을 한 번 더 골라야 한다 — 박자 설정은 남아 있다.

여기서부터가 이 기능의 요점이다. 영상의 시각과 안무표의 카운트를 이어 붙이면, 재생 위치가 안무표 위에 초록 세로선으로 선다. 잇는 방법은 **두 지점을 찍는 것**이다.

1. 영상을 재생한다(영상 화면 안의 유튜브 재생 버튼을 그대로 쓴다).
2. 패널 아래 `여기가 [8x1] 의 [1] 카운트` 를 그대로 두고, 곡에서 `8x1` 의 첫 박이 오는 순간에 `지금 여기` 를 누른다.
3. 안내가 `1/2 — 첫 지점 8x1의 1카운트 = 0:12.3` 으로 바뀌고, 행 칸이 `8x5` 로 저절로 밀린다. **두 지점은 멀수록 정확하기 때문**이다.
4. 계속 들으면서 `8x5` 의 첫 박이 오는 순간에 `지금 여기` 를 한 번 더 누른다.
5. 맨 위 줄이 `BPM 106.7 · 1카운트 = 1박 · 기준 8x1의 1카운트 = 0:12.3` 으로 바뀌고, 그 순간부터 안무표에 초록 세로선이 나타나 곡을 따라 움직인다. 선이 지나가는 블록은 초록 테두리로 밝아지고 다음 블록에 들어서면 앞 블록은 꺼지므로, 영상을 보면서 지금 어느 동작 차례인지 한눈에 보인다.

스윙은 보통 1카운트가 2박이다. 세로선이 곡의 두 배(또는 절반) 속도로 가면 `1카운트 =` 칸을 `2` 로 바꾼다. 박자만 알고 싶으면 `탭` 을 곡에 맞춰 네댓 번 두드리고 `탭으로 BPM 정하기` 를 눌러도 된다.

이제 안무표의 블록을 누르면 영상이 그 대목으로 건너뛰어 재생된다. 눌러 보면서 배치가 실제 동작과 맞는지 확인하고, 어긋나면 3단계처럼 블록을 옮긴다. 정한 BPM 과 시작 지점은 다음 단계의 저장 파일에 함께 들어간다.

> 이 단계에는 **인터넷이 필요하다.** 유튜브의 재생 스크립트를 받아야 하기 때문이고, 못 받으면 패널이 그 사실을 한 줄로 알려 준다. 그리고 **어디까지 봤는지는 저장되지 않는다** — 저장되는 것은 BPM·시작 지점·영상 주소까지다.

### 동작을 놓는 두 가지 길

여기까지 두 방법을 다 썼다. 정리하면 이렇다.

| | `동작 목록` 카드를 끌어다 놓기 | `+ 빠른 배치` 로 격자를 쓸기 |
|---|---|---|
| 길이 | 언제나 `기본 카운트` 값 그대로 | 쓴 만큼. 쓸지 않고 한 번 누르면 `기본 카운트` |
| 동작 고르기 | 카드를 눈으로 찾아 잡는다 | 팝업에서 이름을 쳐서 찾는다 |
| 목록에 없는 동작 | 먼저 `솔로 동작 추가` 로 만들어야 한다 | 그 자리에서 만들며 놓는다 |
| 새 카테고리 | 만들 수 없다 | `✦ 추가 & 배치` 로 만들며 놓는다 |
| 놓은 뒤 길이 맞추기 | 오른쪽 손잡이로 다시 늘려야 한다 | 놓을 때 이미 맞다 |
| 여러 마디에 걸치기 | 놓은 뒤 늘려서 넘긴다 | 쓸면서 다음 행까지 이어진다(마우스) |
| 손해 | 길이를 두 번 손본다. 늘리다 옆 동작과 겹치면 층이 하나 늘어 행이 높아진다 | 팝업이 매번 뜬다. 이미 있는 동작만 놓을 때는 성가시다 |
| 어울리는 때 | 같은 길이를 여러 개 흩뿌릴 때 | 길이가 제각각인 곡을 처음부터 짤 때 |

셋째 길도 있다. `동작 목록` 의 카드를 **한 번 클릭하면** 그 동작이 활성 상태가 되고, 그 뒤 격자를 쓸면 그 동작이 쓴 길이만큼 놓인다. 카드를 다시 누르거나 `Esc` 를 누르면 풀린다.

## 결과 받기

`프로젝트 파일 이름` 칸에 이름을 적고 `프로젝트 저장` 을 누른다. `<적은 이름>-project.json` 이 내려받기 폴더에 떨어진다. 칸을 비워 두면 `project_2026-09-07` 처럼 오늘 날짜가 이름이 된다.

파일 하나에 담기는 것은 사이드바에 적힌 그대로다 — `프로젝트 저장에는 안무표 크기, 카테고리 색상, 동작 목록, 배치 상태가 모두 포함됩니다.` 구체적으로는 이 여섯이다.

- 안무표 크기(마디 수와 한 마디의 카운트 수)
- 카테고리 사전과 각 갈래의 색
- 동작 목록 전체
- 안무표의 모든 배치(겹쳐 쌓은 층 정보까지)
- 루틴 전부(각 루틴의 내부 격자와 즐겨찾기 여부까지)
- 링크 네 가지 — YouTube 주소, 조회된 제목, ClickUp 주소, 직접 추가한 링크들

⚠ **새로고침하면 안무표는 비워진다.** 페이지를 다시 열 때 되살아나는 것은 링크와 즐겨찾기, 그리고 최근 목록뿐이고 배치·루틴은 복원되지 않는다. 저장하지 않고 탭을 닫으면 사라진다.

다만 `프로젝트 저장` 을 한 번이라도 눌렀다면 그 내용이 사이드바의 최근 목록에도 통째로 남는다. 목록의 항목마다 `이름 복사`(`프로젝트 이름을 입력창에 복사`), `부분 불러오기`, `전체 불러오기`, `삭제` 버튼이 있으니 파일을 잃어버렸어도 여기서 되살릴 수 있다. 최근 목록은 이 브라우저에만 있으므로 다른 기기로 옮길 때는 파일이 있어야 한다.

### 되받는 두 가지 길

| | `전체 불러오기` | `부분 불러오기` |
|---|---|---|
| 지금 화면 | 통째로 갈아치운다 | 그대로 두고 파일 내용을 **더한다** |
| 안무표 크기 | 파일 값으로 바뀐다 | 바뀌지 않는다 |
| 배치 | 파일 것만 남는다 | 지금 것 위에 얹는다. 자리가 겹치면 아래층으로 쌓는다 |
| 카테고리·동작 목록 | 파일 것으로 바뀐다 | 없는 것만 더해진다 |
| 루틴 | 파일 것으로 바뀐다 | 없는 것만 더해진다 |
| 링크 | 파일 값으로 바뀐다(파일에 없으면 비워진다) | 건드리지 않는다 |
| 파일 검사 | `moveLibrary` 와 `placements` 가 **둘 다** 있어야 연다 | `placements` 만 있으면 연다 |
| 끝나고 뜨는 말 | 없음 | `병합 완료: 12개 그룹 배치됨` (겹친 것이 있으면 `(3개 충돌 → 아래 레이어)` 가 붙는다) |

여러 사람이 마디를 나눠 만들고 한 표에 합칠 때 쓰는 것이 `부분 불러오기` 다.

## 자주 쓰는 다음 동작

### 되돌리기

`Undo` `Redo` 버튼, 또는 Ctrl(Cmd) + Z 와 Ctrl(Cmd) + Y / Shift + Z 다. 100단계까지 남는다. 되돌려지는 것은 안무표 크기·배치·동작 목록·카테고리·루틴·링크다. **링크는 칸에서 손을 떼거나 `Enter` 를 눌러 값이 확정될 때 한 단계가 쌓인다** — 글자를 치는 동안에는 쌓이지 않는다. 즐겨찾기·선택 표시·정렬 설정·`기본 카운트` 는 되돌려지지 않는다.

⚠ 단축키에 입력창 예외가 없다. 이름 칸 안에서 Ctrl + Z 를 누르면 글자가 아니라 안무가 되돌아간다. 입력창에서는 마우스로 지운다.

### 동작 카드 손보기

카드의 이름을 **더블클릭하거나 우클릭하면**(휴대폰에서는 480ms 길게 누르면, 8px 이상 움직이면 취소된다) `이름 변경` / `카테고리: …` / `삭제` 메뉴가 뜬다. 카드에 직접 달린 갈래 선택 상자로도 카테고리를 바꿀 수 있다.

`×` 나 메뉴의 `삭제` 는 한 번 누르면 라벨이 `정말요?` 로 바뀌고, **2초 안에** 다시 눌러야 실제로 지워진다. 이 방식은 `전체 초기화(링크 포함)`, 카테고리 삭제, 루틴 삭제에도 똑같이 쓰인다.

`★` 는 즐겨찾기다(`즐겨찾기 (빠른 배치에 표시)`). 켜 두면 `동작 목록` 위쪽 `★ 즐겨찾기` 묶음으로 올라가고, 빠른 배치 팝업에서 검색어 없이도 맨 위에 나온다.

### 카테고리 색 바꾸기

`카테고리 관리` 의 색 네모를 눌러 색을 고르면 범례·동작 목록·안무표가 바로 따라 바뀐다. 이름 칸을 고치면 화면 전체의 표기가 바뀐다. 갈래는 최소 하나가 남아야 해서, 마지막 하나를 지우려 하면 `카테고리는 최소 1개 이상 있어야 합니다.` 가 뜬다.

### 동작 목록과 카테고리만 주고받기

`동작 저장` 은 `<이름>-moves.json`, `카테고리 저장` 은 `<이름>-categories.json` 을 만든다. 각각 `동작 열기` `카테고리 열기` 로만 열린다. 팀에서 쓰는 동작 이름을 통일할 때 안무 없이 이것만 돌리면 된다.

### 앱 안에서 문서 읽기

안무표 위 도구 모음의 `문서` 버튼을 누르면 이 튜토리얼과 [기능 설명서](FEATURES.md)를 비롯한 프로젝트 문서를 `시작하기` · `기능과 사용법` · `바뀐 것` · `만드는 사람을 위해` 갈래로 묶어 앱 안에서 바로 읽을 수 있다.

### 휴대폰과 태블릿

- 격자를 쓸면 페이지가 같이 스크롤된다. 화면에 떠 있는 `사이드바` · `보드` 잠금 버튼으로 스크롤을 잠그고 그린 뒤 다시 풀면 된다.
- `동작 목록` 카드는 **왼쪽 색 칩을 180ms 길게 눌러야** 끌리기 시작한다.
- 블록 삭제는 더블클릭 대신 **300ms 안의 두 번 탭**이다.
- 사이드바와 안무표 사이의 경계선을 끌면 위아래 비율을 조절할 수 있다.
- 터치에서는 Alt 복사, 루틴 카드 배치, 행을 넘기는 쓸기가 되지 않는다. 이것들은 마우스가 있는 기기에서 한다.
- 영상 패널은 안무표 **위**로 올라가고 처음 열 때는 접힌 채로 열린다. 세로 자리가 빠듯해서다 — 헤더의 `펼치기` 로 편다.

## 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 화면이 빈 채로 아무것도 안 뜬다 | `index.html` 을 더블클릭해 `file://` 로 열었다. 그 상태에서는 ES 모듈과 문서 `fetch` 가 막힌다 | 터미널에서 `python3 -m http.server 8000` 을 켜고 `http://localhost:8000` 으로 다시 연다 |
| 블록을 늘렸더니 겹친 동작이 아래층으로 내려가 행이 두 줄이 됐다 | 겹치면 지우지 않고 쌓는 것이 규칙이다. 늘린 블록이 빈 층을 찾아 내려간 것이고, 아무것도 지워지지 않았다 | 겹치지 않게 하려면 `Undo`(Ctrl/Cmd + Z) 로 되돌린 뒤 짧게 늘리거나 겹친 블록을 먼저 옮긴다. 겹침이 없어지면 행 높이도 한 줄로 돌아온다 |
| `전체 초기화(링크 포함)` 을 눌렀더니 YouTube 주소까지 지워졌다 | 버튼 이름 그대로다. 초기화는 배치뿐 아니라 링크 네 가지를 함께 비우고 즉시 브라우저에 기록한다 | `Undo`(Ctrl/Cmd + Z) 한 번이면 배치와 링크가 함께 돌아오고, 되돌아온 링크는 브라우저에도 다시 기록되니 새로고침해도 남는다. 단 YouTube **제목**은 주소보다 늦게 도착하므로, 주소를 넣자마자 되돌리면 제목이 함께 사라진다 |
| 새로고침했더니 안무표가 비었다 | 배치와 루틴은 브라우저에 저장되지 않는다. 다시 열 때는 링크·즐겨찾기·최근 목록만 살아난다 | 사이드바 최근 목록에서 `전체 불러오기`. 목록에도 없으면 되살릴 방법이 없으니 앞으로는 `프로젝트 저장` 을 먼저 한다 |
| 휴대폰에서 스크롤과 드래그가 엉킨다 | 격자를 쓰는 동작이 페이지 스크롤과 겹친다 | 화면에 떠 있는 `보드`(또는 `사이드바`) 잠금 버튼으로 스크롤을 잠그고 그린 뒤 다시 눌러 푼다 |
| 저장한 파일이 안 열린다 (`올바른 프로젝트 파일이 아닙니다.` 또는 `잘못된 프로젝트 파일 형식입니다.`) | 프로젝트 파일이 아니거나 내용이 깨졌다. `전체 불러오기` 는 `moveLibrary` 와 `placements` 가 둘 다 있어야 통과한다 | `-moves.json` 은 `동작 열기`, `-categories.json` 은 `카테고리 열기` 로 연다. 배치만 든 파일이라면 `부분 불러오기` 로는 열린다 |
| 새 루틴을 놓았더니 예상보다 훨씬 넓게 자리를 먹는다 | 루틴 블록의 길이는 채운 양이 아니라 `박자 × 행` 이다. 기본값 `8박자 × 4행` 은 32카운트, 곧 4마디다 | `✏` 로 편집기를 열어 `행` 을 줄인 뒤 다시 놓는다 |
| 마디 수를 줄였더니 아래쪽 블록이 사라졌다 | `안무표 크기` 를 줄이면 범위를 벗어난 배치가 삭제된다 | `Undo` 로 되돌린 뒤 숫자를 다시 올린다 |
| 팝업에서 이름을 치고 `Enter` 를 눌렀더니 카테고리 화면으로 넘어갔다 | 빠른 배치 팝업의 `Enter` 기본값은 "새 동작 추가"다. 검색 결과가 보여도 화살표로 고르기 전에는 선택되지 않는다 | `↓` 로 항목을 고른 다음 `Enter` 를 누르거나, 항목을 마우스로 클릭한다 |

## 전체 흐름

여기까지의 순서를 한 덩어리로 적으면 이렇다.

```
python3 -m http.server 8000        # 터미널은 열어 둔다
http://localhost:8000              # 브라우저에서 연다

  안무표 크기 = 8                  마디 수를 정한다
  동작 목록 카드를 끌어다 놓기       → 오른쪽 손잡이로 길이 조절
  [+ 빠른 배치] 켜고 격자를 쓸기     → 동작 선택 팝업에서 고르기
      없는 동작이면 [+] → 카테고리 → [✦ 추가 & 배치]
  같은 칸에 다시 놓기                → 아래층으로 쌓인다
      오른쪽 손잡이로 덮어도 마찬가지다 — 넷 다 지우지 않는다
  블록 여러 개 클릭                  → [루틴으로 편성 (N)]
      또는 [+ 새 루틴] → 박자·행 → [✕ 닫기] → 카드를 안무표로 드래그
  ▶ YouTube 주소 붙여넣기            → 700ms 뒤 제목이 붙는다
  [▶ 영상 패널] → 재생 → [지금 여기] 두 번  → BPM 과 시작 지점이 정해진다
      블록을 누르면 그 대목으로 건너뛴다

  프로젝트 파일 이름 입력 → 프로젝트 저장 → <이름>-project.json
      ⚠ 저장 전에 새로고침하면 안무표가 비워진다
```
