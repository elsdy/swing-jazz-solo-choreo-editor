# 기능 설명서

이미 쓰고 있는데 한 가지가 궁금할 때 보는 목차다. 기능마다 **무엇을 하는지 · 어디에 있는지 · 어떻게 쓰는지 · 주의할 점** 네 항목이 같은 차례로 있고, 한 덩이 안에서 답이 끝나도록 썼다. 처음부터 순서대로 따라가려면 [튜토리얼](TUTORIAL.md)을, 실행 방법과 저장소 구조는 [프로젝트 소개](README.md)를 본다.

## 안무표에 놓기

### 동작 목록에서 끌어다 놓기

**무엇을 하는지** — 동작 카드를 안무표 칸에 떨어뜨려 그 칸부터 `기본 카운트` 길이의 블록을 만든다.

**어디에 있는지** — 왼쪽 사이드바 맨 아래 `동작 목록` 밑의 카드들. 놓는 곳은 오른쪽 `8x8 안무 테이블` 격자다.

**어떻게 쓰는지** — 카드를 잡아 격자 위로 끌면 점선 미리보기와 `Nc` 배지가 따라온다. 놓으면 그 자리에 블록이 생기고, 행 끝을 넘는 길이는 다음 행으로 이어져 그려진다. 루틴 편집 패널이 열려 있으면 그쪽 격자에도 놓을 수 있다.

**주의할 점** — 카드 안의 카테고리 드롭다운이나 `★` · `×` 버튼을 잡고 끌면 드래그가 시작되지 않는다. 격자 밖에 놓으면 아무 일도 일어나지 않는다. 이미 블록이 있는 자리에 놓아도 그 블록은 지워지지 않고, 새 블록이 아래층으로 쌓인다.

### 동작을 고른 뒤 격자에 그려 놓기

**무엇을 하는지** — 동작 하나를 골라 둔 상태로 격자를 쓸어, 끌어낸 길이만큼 한 번에 배치한다.

**어디에 있는지** — `동작 목록`의 카드를 한 번 클릭하면 카드가 밝게 표시된다. 그 상태로 안무표의 빈 칸을 누른 채 끈다.

**어떻게 쓰는지** — 카드 클릭(다시 클릭하면 해제) → 빈 칸에서 누르기 → 좌우·아래로 끌면 `Nc` 미리보기가 실시간으로 바뀐다 → 손을 떼면 확정된다. 여러 행에 걸쳐 끌면 행을 넘어가는 카운트로 센다.

**주의할 점** — `Esc` 로 해제된다. `+ 빠른 배치`를 켜면 골라 둔 동작이 강제로 해제된다. 이미 놓인 블록이나 핸들 위에서 시작하면 무시된다. 최종 길이는 `기본 카운트`보다 짧아지지 않아, 미리보기에 `1c`가 보여도 놓으면 `기본 카운트`만큼 배치될 수 있다. 이 방법은 메인 안무표에서만 되고 루틴 편집 패널에서는 동작하지 않는다.

### `+ 빠른 배치`로 격자에서 바로 찾아 놓기

**무엇을 하는지** — 사이드바를 거치지 않고 격자를 직접 눌러 동작 검색 팝업을 열고 그 자리에 배치한다.

**어디에 있는지** — 안무표 위 도구 모음의 `+ 빠른 배치` 버튼. 켜면 버튼이 강조된다. 루틴 편집 패널에도 같은 이름의 버튼이 따로 있다.

**어떻게 쓰는지** — 버튼을 켜고 빈 칸을 클릭하면 `기본 카운트` 길이로, 누른 채 끌면 끌어낸 길이로 자리가 잡힌다. 손을 떼면 `동작 선택` 팝업이 뜬다. `동작 이름 검색...`에 이름을 치거나, 아무것도 치지 않고 위쪽 `즐겨찾기` 목록에서 고른다. 항목을 클릭하면 바로 배치된다.

**주의할 점** — 이 모드를 켜면 골라 둔 동작이 해제된다. 팝업 바깥을 누르면 닫히고, 다시 버튼을 눌러 끄면 미리보기도 지워진다. 루틴 편집 패널의 팝업은 제목이 `동작 선택 (루틴)`이고 화살표 · `Enter` · `Esc` 가 듣지 않아 클릭으로만 고를 수 있다.

### 빠른 배치에서 없는 동작을 즉석에서 만들기

**무엇을 하는지** — 목록에 없는 이름을 입력해 카테고리까지 정하고, 동작을 등록하면서 동시에 그 자리에 배치한다.

**어디에 있는지** — `동작 선택` 팝업 검색창 오른쪽의 초록색 `+` 버튼(`새 동작으로 추가`), 또는 검색 결과가 없을 때의 `Enter`.

**어떻게 쓰는지** — 이름을 입력하면 `"…" 와 일치하는 동작이 없습니다. Enter를 눌러 새 동작으로 추가` 안내가 뜬다. `Enter` 나 `+` 를 누르면 `카테고리 선택` 화면으로 넘어가고, 위에 `동작: "…"` 배지가 붙는다. 기존 카테고리를 클릭하거나, `카테고리 검색...`에 없는 이름을 쳐서 색을 고른 뒤 `✦ 추가 & 배치`를 누른다. `←` 로 앞 화면으로 돌아간다.

**주의할 점** — 검색 결과가 있어도 `Enter` 의 기본 동작은 '새 동작 추가'다. 목록에서 고르려면 `↓` 로 항목을 먼저 짚어야 한다. 같은 이름의 동작이 이미 있으면 새로 만들지 않고 그것을 다시 쓰는데, 이때 방금 고른 카테고리는 반영되지 않는다 — 카테고리만 새로 생기고 그것을 쓰는 동작은 하나도 없는 상태가 남는다.

### 손가락으로 끌어다 놓기

**무엇을 하는지** — 모바일에서 동작 카드를 길게 눌러 고스트 칩을 띄우고, 손가락을 떼는 칸에 배치한다.

**어디에 있는지** — 사이드바 `동작 목록`의 동작 카드.

**어떻게 쓰는지** — 카드를 0.18초 길게 누르면 손가락을 따라다니는 칩이 생긴다. 안무표 위로 옮기면 대상 칸이 밝아지고 미리보기가 뜨며, 손을 떼면 `기본 카운트` 길이로 놓인다.

**주의할 점** — 메인 안무표에만 놓인다. 루틴 편집 패널에는 이 경로가 없다. 롱프레스 타이머가 손가락 이동으로 취소되지 않아, 동작 목록을 스크롤하려고 손가락을 대고 있어도 0.18초가 지나면 드래그가 시작된다. 그리는 동안 화면이 함께 스크롤되면 화면 구석의 `사이드바` · `보드` 잠금 버튼을 쓴다.

## 놓은 블록 고치기

### 블록 옮기기

**무엇을 하는지** — 놓은 블록을 여러 행에 걸친 조각까지 통째로 다른 자리로 옮긴다.

**어디에 있는지** — 안무표 블록의 왼쪽 가장자리 핸들(`위치 이동`).

**어떻게 쓰는지** — 왼쪽 핸들을 잡아 끈다. 끄는 동안 대상 칸이 밝아지고 미리보기가 뜨며, 놓으면 그 자리부터 다시 계산된다. 모바일에서는 같은 핸들을 손가락으로 눌러 끈다.

**주의할 점** — 안무표 끝 가까이 옮기면 남은 칸 수만큼 길이가 잘린다. 겹치는 자리의 기존 블록은 지워지지 않고, 옮겨 온 블록이 빈 층을 찾아 아래로 쌓인다.

### 블록 복사하기

**무엇을 하는지** — 원본을 남긴 채 같은 내용의 블록을 새로 만든다.

**어디에 있는지** — 안무표 블록의 왼쪽 핸들. 마우스 전용이다.

**어떻게 쓰는지** — `Alt`(맥은 `Option`)를 누른 채 왼쪽 핸들을 끌어 원하는 자리에 놓는다.

**주의할 점** — 복사 여부는 끌기를 **시작하는 순간의** `Alt` 만 본다. 끌던 도중에 눌러도 복사로 바뀌지 않는다. 터치에는 복사 제스처가 없다. 복사 뒤에는 층 정리를 하지 않아 위층이 빈 채로 남을 수 있다.

### 블록 길이 조절

**무엇을 하는지** — 블록의 카운트를 늘리거나 줄인다. 행 끝을 넘겨 끌면 다음 행으로 이어진다.

**어디에 있는지** — 안무표 블록의 오른쪽 가장자리 핸들(`길이 조절`).

**어떻게 쓰는지** — 오른쪽 핸들을 눌러 좌우로 끈다. 끄는 동안 점선 미리보기와 `Nc` 배지가 실시간으로 바뀌고, 손을 떼면 확정된다. 시작점은 고정이라 오른쪽·아래로만 자란다.

**주의할 점** — 늘려서 다른 블록과 겹쳐도 **그 블록은 지워지지 않는다.** 늘린 블록이 빈 층을 찾아 아래로 내려가고, 겹친 블록은 제자리에 그대로 남는다 — 끌어다 놓기·옮기기·복사와 같은 규칙이다(2026-09-07 이전에는 길이 조절만 달라서, 겹친 블록이 확인 없이 통째로 지워졌다). 여러 행에 걸친 블록은 **그룹 전체가 같은 층**을 쓰므로, 한 행에서만 겹쳐도 다른 행의 조각까지 함께 한 층 내려간다. 안무표 끝을 넘겨 늘리면 넘친 만큼은 조용히 잘린다. 메인 안무표의 루틴 블록은 길이 조절이 막혀 있다.

**네 조작의 겹침 규칙은 같다.** 어느 방법으로 겹치든 결과가 같아, "이 방법으로 겹치면 지워지나"를 외울 필요가 없다.

| 겹치는 방법 | 그 자리에 있던 블록 | 겹친 쪽 |
|---|---|---|
| `동작 목록`·`+ 빠른 배치` 로 놓기 | 남는다 | 새 블록이 빈 층으로 내려간다 |
| 왼쪽 핸들로 옮기기 | 남는다 | 옮긴 블록이 빈 층으로 내려간다 |
| `Alt` + 왼쪽 핸들로 복사하기 | 남는다 | 복사본이 빈 층으로 내려간다 |
| 오른쪽 핸들로 길이 늘리기 | 남는다 | 늘린 블록이 빈 층으로 내려간다 |

겹치지 않으면 층은 그대로다. 다만 겹침이 사라진 행은 자동으로 층이 위로 당겨지므로, 혼자 아래층에 떠 있던 블록은 다음 조작에서 맨 위층으로 올라온다(복사만 이 정리를 하지 않는다).

### 블록 지우기

**무엇을 하는지** — 여러 행에 걸친 조각까지 한 블록 전체를 지운다.

**어디에 있는지** — 안무표 블록의 몸통(핸들이 아닌 부분).

**어떻게 쓰는지** — 마우스는 더블클릭, 모바일은 같은 블록을 0.3초 안에 두 번 탭한다. 지운 뒤 그 행의 층이 자동으로 정리된다.

**주의할 점** — 확인 절차가 없다. 되돌리려면 `Undo` 뿐이다. 메인 안무표의 루틴 블록은 이 방법으로 지워지지 않고, 블록을 눌러 나오는 팝업의 `× 삭제`를 써야 한다. 루틴 편집 패널 안에서는 루틴 판정이 없어 더블클릭 삭제가 그대로 듣는다.

### 블록 이름과 길이 확인

**무엇을 하는지** — 블록의 이름과 총 카운트를 `이름 8c` 형태의 검은 툴팁으로 띄운다.

**어디에 있는지** — 안무표의 블록 위.

**어떻게 쓰는지** — 마우스를 블록 위에 올리면 뜨고 벗어나면 사라진다. 모바일에서는 왼쪽 핸들을 누르고 있는 동안 뜬다.

**주의할 점** — 화면이 다시 그려질 때마다 툴팁은 강제로 숨겨진다. 길이 조절을 시작해도 사라진다.

## 동작과 카테고리 갖추기

### 동작 추가

**무엇을 하는지** — 동작 목록에 새 동작을 등록한다. 안무표에 놓이지는 않는다.

**어디에 있는지** — 사이드바 `솔로 동작 추가` 카드. 이름 칸(`예: Shorty George`), 카테고리 드롭다운, `추가` 버튼이 한 줄에 있다.

**어떻게 쓰는지** — 이름을 넣고 카테고리를 고른 뒤 `추가`를 누른다. 목록이 갱신되고 입력칸은 비워진다.

**주의할 점** — 이름이 비면 `동작 이름을 입력해 주세요.` 가 뜬다. 같은 이름을 막지 않는데, 안무표의 블록은 **이름으로** 동작과 이어져 있다. 같은 이름의 동작을 둘 만들면 그중 하나만 지워도 두 동작의 블록이 모두 안무표에서 사라진다.

### 동작 검색과 정렬

**무엇을 하는지** — 동작 목록을 이름으로 걸러 내고 정렬 기준과 방향을 바꾼다.

**어디에 있는지** — 사이드바 `동작 목록` 아래의 `동작 검색...` 칸과 그 밑의 버튼 넷: `가나다` · `추가순` · `카테고리` · `↑`(누르면 `↓`).

**어떻게 쓰는지** — 검색창에 치면 바로 걸러진다. 기준 버튼 하나를 눌러 정렬을 바꾸고, 화살표 버튼으로 방향을 뒤집는다. `★` 를 켠 동작은 언제나 위쪽 `★ 즐겨찾기` 칸에 따로 모인다.

**주의할 점** — 검색어와 정렬 설정은 어디에도 저장되지 않아 새로고침하면 `가나다` · `↑` 로 돌아간다. `추가순`의 `↑` 는 최근에 만든 것이 위다. `카테고리` 정렬은 카테고리 사전의 순서를 따르는데, 카테고리가 삭제된 동작은 언제나 맨 앞(방향을 뒤집으면 맨 뒤)에 온다. 프로젝트를 저장했다 불러오면 카테고리 순서가 가나다순으로 재배열되어 `카테고리` 정렬 결과가 저장 전과 달라진다.

### 동작 즐겨찾기

**무엇을 하는지** — 자주 쓰는 동작을 목록 위쪽 `★ 즐겨찾기` 칸과 빠른 배치 팝업 위쪽에 고정한다.

**어디에 있는지** — 동작 카드 오른쪽의 `★` 버튼(`즐겨찾기 (빠른 배치에 표시)`). 빠른 배치 팝업의 각 항목에도 같은 버튼이 있다.

**어떻게 쓰는지** — `★` 를 눌러 켜고 끈다. 누르는 즉시 이 브라우저에 저장된다.

**주의할 점** — 즐겨찾기는 동작 id 가 아니라 **이름으로** 기억된다. 동작 이름을 바꾸면 즐겨찾기가 풀린다. 이 브라우저의 저장소(localStorage)에만 남고 프로젝트 파일에는 들어가지 않아, 파일을 다른 기기에서 열면 따라오지 않는다. `Undo` 대상도 아니다.

### 동작의 카테고리 바꾸기

**무엇을 하는지** — 동작이 속한 카테고리를 바꾸고, 안무표에 놓인 블록의 색까지 함께 갱신한다.

**어디에 있는지** — 동작 카드 안의 색점 옆 드롭다운.

**어떻게 쓰는지** — 드롭다운에서 다른 카테고리를 고른다. 목록과 안무표가 즉시 반영되고 기록에 남는다.

**주의할 점** — 안무표의 블록을 **이름으로** 찾아 바꾸므로, 이름이 같은 동작이 둘 있으면 두 쪽 블록이 전부 함께 바뀐다. 루틴 안에 들어 있는 배치는 바뀌지 않는다.

### 동작 이름 변경과 메뉴

**무엇을 하는지** — 동작의 이름을 바꾸거나, 카테고리를 키로 직접 바꾸거나, 동작을 지운다.

**어디에 있는지** — 동작 카드의 이름 글자(`더블클릭, 우클릭 또는 길게 눌러 메뉴 열기`).

**어떻게 쓰는지** — 이름을 더블클릭하면 `동작 이름 변경` 입력창이 바로 뜬다. 우클릭하거나 모바일에서 0.48초 길게 누르면 `이름 변경` · `카테고리: <현재 라벨>` · `삭제` 메뉴가 열린다. `삭제`는 2초 안에 한 번 더 눌러야(`정말요?`) 실행된다.

**주의할 점** — **이름을 바꾸면 이름이 같은 배치가 안무표에서 전부 함께 바뀐다.** 반대로 루틴 편집 보드와 루틴 정의 안의 배치는 옛 이름 그대로 남아, 이름을 바꾼 뒤 그 루틴을 다시 놓으면 옛 이름의 블록이 생긴다. 이름을 바꾸면 즐겨찾기도 풀린다. 이름을 비우면 `이름을 비워둘 수 없습니다.` 가 뜬다. 메뉴의 카테고리 변경은 화면에 보이는 라벨이 아니라 **내부 키**를 입력해야 하고, 없는 키를 넣으면 `존재하는 카테고리 키를 입력해 주세요.` 가 뜬다 — 키를 확인할 방법은 화면에 없다.

### 동작 삭제

**무엇을 하는지** — 동작을 목록에서 지우고, 안무표에 놓인 같은 이름의 블록도 함께 없앤다.

**어디에 있는지** — 동작 카드 맨 오른쪽의 `×` 버튼(`삭제`). 이름 메뉴의 `삭제` 도 같은 일을 한다.

**어떻게 쓰는지** — `×` 를 누르면 라벨이 `정말요?` 로 바뀐다. 2초 안에 다시 누르면 실행되고, 그냥 두면 취소된다.

**주의할 점** — **안무표에 놓인 같은 이름의 블록이 전부 함께 사라진다.** 루틴 안의 배치는 지워지지 않고, 목록에 없는 이름의 배치로 남는다. 되돌리려면 `Undo` 를 쓴다.

### 카테고리 색 바꾸기

**무엇을 하는지** — 카테고리의 색을 바꾸고 범례 · 동작 목록 · 안무표 블록에 즉시 반영한다.

**어디에 있는지** — 사이드바 `카테고리 관리` 카드에서 각 줄 맨 왼쪽의 색 사각형(`색상 변경`).

**어떻게 쓰는지** — 사각형을 눌러 색을 고른다. 고르는 동안 화면이 따라 바뀌고, 색을 확정하면 기록에 남는다.

**주의할 점** — 안무표의 루틴 블록은 카테고리 색이 아니라 루틴 자신의 색을 쓰므로 여기서 바꿔도 달라지지 않는다. 루틴 편집 패널은 열려 있을 때만 함께 다시 그려진다. **블록 위 글자색은 고를 수 없고 배경에 따라 저절로 정해진다** — 검정과 흰색 중 그 배경에서 더 잘 읽히는 쪽이 붙으므로, 색을 어둡게 하면 글자가 흰색으로 바뀐다.

### 카테고리 이름 변경 · 즐겨찾기 · 삭제

**무엇을 하는지** — 카테고리의 표시 이름을 바꾸고, 빠른 배치 팝업 위쪽 고정 여부를 정하고, 카테고리를 지운다.

**어디에 있는지** — `카테고리 관리` 카드의 각 줄: `카테고리 이름` 입력칸, `★`(`즐겨찾기 (빠른 배치에 표시)`), `×`(`카테고리 삭제`).

**어떻게 쓰는지** — 이름을 고치고 칸 밖을 클릭하면 화면 전체에 반영된다. `★` 는 눌러 켜고 끈다. `×` 는 2초 안에 다시 눌러(`정말요?`) 지운다.

**주의할 점** — 마지막 하나는 지울 수 없다(`카테고리는 최소 1개 이상 있어야 합니다.`). **카테고리를 지우면 그것을 쓰던 모든 동작과 안무표 배치가 첫 번째 카테고리로 강제로 옮겨진다** — 되돌리는 방법은 `Undo` 뿐이다. 루틴 안의 배치는 옮겨지지 않고 지워진 키를 든 채 남아 회색 기본색으로 그려진다. 카테고리 즐겨찾기는 이 브라우저에만 저장되고 프로젝트 파일에는 들어가지 않는다.

## 루틴으로 묶기

### 새 루틴 만들기

**무엇을 하는지** — 8박자 × 4행짜리 빈 루틴을 만들고 곧바로 편집 패널을 연다.

**어디에 있는지** — 사이드바 `루틴 목록` 제목 오른쪽의 `+ 새 루틴` 버튼. 루틴이 하나도 없으면 `아직 루틴이 없습니다. + 새 루틴을 눌러 만들어 보세요.` 가 보인다.

**어떻게 쓰는지** — 버튼을 누르면 `루틴 N` 이라는 이름의 루틴이 목록 맨 뒤에 생기고 편집 패널이 열린다.

**주의할 점** — 이름이 루틴 개수를 기준으로 정해져, 가운데 것을 지우고 새로 만들면 이름이 겹칠 수 있다. 색은 여덟 색을 돌려 쓰며 목록의 색 칩과 안무표 블록이 같은 색을 쓰는데, 색을 직접 고를 수는 없다. 그 순번이 저장되지 않아 새로고침하거나 프로젝트를 불러오면 처음 색부터 다시 나오고, 그러면 서로 다른 루틴이 같은 색을 쓸 수 있다.

### 놓은 배치를 골라 루틴으로 편성

**무엇을 하는지** — 안무표에 이미 놓인 블록 여러 개를 골라 하나의 루틴으로 새로 만든다.

**어디에 있는지** — 블록을 클릭해 고르면 도구 모음에 숨어 있던 `루틴으로 편성 (N)` 버튼이 나타난다.

**어떻게 쓰는지** — 블록을 하나씩 클릭해 고른다(다시 클릭하면 풀린다). 버튼을 누르면 고른 블록을 행 → 칸 순서로 정렬해 카운트를 합치고, 안무표와 같은 칸 수로 필요한 행을 잡아 루틴을 만든 뒤 편집 패널을 연다.

**주의할 점** — **고른 원본 배치는 안무표에 그대로 남는다.** 옮겨지는 것이 아니다. 루틴 블록은 클릭하면 선택 대신 팝업이 떠서 편성에 넣을 수 없다. 빈 곳을 클릭하거나 `Undo` 를 하면 선택이 전부 풀린다. `전체 초기화(링크 포함)` 이나 `전체 불러오기` 뒤에는 사라진 블록을 가리키는 선택이 남아 버튼이 계속 떠 있을 수 있고, 그 상태로 누르면 아무 일도 일어나지 않는다.

### 루틴 카드 다루기

**무엇을 하는지** — 루틴을 목록 위에 고정하거나, 편집하거나, 지우거나, 이름을 바꾸거나, 안무표에 블록으로 놓는다.

**어디에 있는지** — 사이드바 `루틴 목록`의 각 카드. 색칩과 이름, `N박자 × M행` 메타, 그리고 `★` · `✏`(`루틴 편집`) · `×`(`루틴 삭제`) 버튼이 있다. 목록 위에는 `루틴을 드래그해서 안무표에 배치하거나, ✏ 버튼으로 편집하세요.` 라고 적혀 있다.

**어떻게 쓰는지** — `★` 로 위쪽 `★ 즐겨찾기` 칸에 고정한다. `✏` 로 편집 패널을 연다. 이름이나 메타를 더블클릭하면 `루틴 이름` 입력창이 뜬다. 카드를 안무표로 끌어다 놓으면 행 × 칸 수만큼의 루틴 블록이 놓인다.

**주의할 점** — **루틴을 지우면 안무표에 놓여 있던 그 루틴의 블록도 전부 함께 사라진다.** 삭제는 2초 안에 다시 눌러(`정말요?`) 실행되고, `Undo` 로 루틴과 블록이 함께 돌아온다. 이름을 바꾸면 안무표의 블록 이름도 같이 바뀐다. 카드를 끌어다 놓는 것은 마우스에서만 되고(터치 경로가 없다), 끄는 동안 미리보기가 그려지지 않는다.

### 안무표에 놓인 루틴 블록

**무엇을 하는지** — 안무표의 루틴 블록에서 그 루틴을 열거나, 그 자리의 블록만 없앤다.

**어디에 있는지** — 안무표의 루틴 블록을 한 번 클릭하면 뜨는 작은 팝업. 맨 위에 루틴 이름이 적혀 있고 `✏ 편집` 과 `× 삭제` 가 있다.

**어떻게 쓰는지** — `✏ 편집` 은 편집 패널을 연다. `× 삭제` 는 그 자리의 루틴 블록만 지운다. 팝업 바깥을 누르면 닫힌다.

**주의할 점** — `× 삭제` 는 안무표의 블록만 지우고 루틴 자체는 목록에 남는다 — 루틴 카드의 `×` 와 다르다. 루틴 블록은 더블클릭 삭제와 길이 조절이 막혀 있고 왼쪽 핸들로 옮기는 것만 된다. 일반 선택이 되지 않아 `루틴으로 편성` 에 넣을 수 없다.

### 루틴 편집 패널

**무엇을 하는지** — 루틴 전용 격자에 동작을 놓고 옮기고 지우며, 박자(칸)와 행 수를 조절한다.

**어디에 있는지** — 메인 안무표 오른쪽에 열리는 패널(폭이 좁으면 화면 전체를 덮는다). 제목은 루틴 이름, 부제는 `N박자 × M행` 이다. 처음 마크업의 제목은 `루틴 편집`, 부제는 `이름을 클릭해 편집` 이다.

**어떻게 쓰는지** — 메인 안무표와 같은 조작이 그대로 듣는다(끌어다 놓기, 핸들로 옮기기와 길이 조절, 더블클릭 삭제). `박자` 와 `행` 알약의 `−` · `+` 나 숫자 입력으로 크기를 바꾸고, `+ 빠른 배치` 로 팝업 배치를 하고, 패널 안의 `Undo` · `Redo` 로 되돌린다. `초기화` 는 배치를 비우고 `✕ 닫기` 로 닫는다. 제목을 더블클릭하면 이름을 바꿀 수 있다.

**주의할 점** — `행` 을 줄이면 넘치는 배치가 **숨겨질 뿐** 사라지지 않아 다시 늘리면 되살아난다. 그러나 `박자`(칸)를 줄이면 넘치는 길이가 실제로 잘려 없어진다. `초기화` 에는 확인 절차가 없다. 패널의 되돌리기 기록은 패널을 열 때마다 새로 시작하고 닫으면 사라진다. `Ctrl+Z` 는 언제나 메인 안무표로 가므로 패널 안에서는 버튼을 써야 한다. 루틴 격자에는 `intro` 행이 없고, 동작 카드를 골라 그리는 방식도 듣지 않는다.

### 루틴을 고치면 안무표가 따라온다

**무엇을 하는지** — 루틴의 박자·행을 바꾸면 총 카운트가 달라지므로, 안무표에 놓인 그 루틴 블록의 길이도 자동으로 다시 계산된다.

**어디에 있는지** — 따로 조작할 곳이 없다. 루틴 편집 패널에서 무엇을 하든 메인 안무표가 함께 갱신된다.

**어떻게 쓰는지** — 편집 패널에서 크기나 내용을 바꾸면 곧바로 반영된다. 편집이 끝나면 `✕ 닫기` 로 닫는다.

**주의할 점** — 다시 계산한 블록이 안무표 마지막 행을 넘어가면 넘친 만큼 경고 없이 사라지고, 루틴을 다시 줄여도 돌아오지 않는다. 다시 놓인 루틴 블록은 늘 맨 위층으로 올라오고 겹침 검사를 하지 않아, 루틴이 커지면 다른 블록 위에 겹쳐 그려질 수 있다.

## 안무표 다루기

### 안무표 크기

**무엇을 하는지** — 안무표의 마디(행) 수를 1에서 128 사이로 바꾼다.

**어디에 있는지** — 안무표 위 도구 모음 왼쪽의 `안무표 크기` 알약. `8 x [숫자]` 모양이고 `−` · `+` 버튼이 붙어 있다.

**어떻게 쓰는지** — 숫자를 직접 넣고 `Enter` 를 치거나 `−` · `+` 를 누른다. 행 라벨이 `8x1` · `8x2` … 로 늘고 제목도 `8xN 안무 테이블` 로 바뀐다.

**주의할 점** — 라벨은 `8 x N` 이지만 바뀌는 값은 **행 수**다. 한 행의 칸 수는 화면에서 바꿀 수 없고 프로젝트 파일을 불러올 때만 달라지며, 제목은 칸 수와 상관없이 늘 `8x` 로 시작한다. **행 수를 줄이면 잘려 나간 행의 배치가 삭제된다** — 다시 늘려도 돌아오지 않고 `Undo` 만이 방법이다. 맨 위 `intro` 행은 늘 하나 더 있으며 이 숫자에 포함되지 않는다.

### 기본 카운트

**무엇을 하는지** — 길이를 끌지 않고 그냥 놓았을 때 생기는 블록의 기본 길이를 정한다.

**어디에 있는지** — 도구 모음의 `기본 카운트` 알약.

**어떻게 쓰는지** — 숫자를 넣거나 `−` · `+` 를 누른다. 다음에 놓는 블록부터 적용된다.

**주의할 점** — 이 값은 **어디에도 저장되지 않는다.** 프로젝트 파일에도 브라우저에도 남지 않아 새로고침하면 언제나 1로 돌아간다. `−` · `+` 는 1에서 64 사이로 묶어 주지만 직접 입력에는 상한 검사가 없다. 1 미만을 넣으면 이전 값으로 되돌아간다. `Undo` 대상도 아니다.

### 비고란

**무엇을 하는지** — 각 행에 놓인 동작의 이름과 위치·길이를 자동으로 요약해 보여 준다.

**어디에 있는지** — 안무표 오른쪽 `비고` 열. 왼쪽 첫 열은 `마디` 이고 행 라벨은 `intro` · `8x1` · `8x2` … 로 붙는다.

**어떻게 쓰는지** — 볼 것만 있고 쓸 것은 없다. 일반 동작은 `이름 (8x2 : 3 [4])` 처럼 시작 마디 · 시작 카운트 · 전체 길이를, 루틴은 `▶ 루틴 이름` 을 보여 준다. 아무것도 없는 행에는 `-` 가 뜬다.

**주의할 점** — 사용자가 고쳐 쓸 수 없다. 여러 행에 걸친 동작은 **첫 번째 행의 비고에만** 나온다. 맨 위 `intro` 행의 비고 표기는 `8x0` 으로 적힌다.

## 저장하고 합치기

### 프로젝트 저장

**무엇을 하는지** — 지금 상태 전체를 JSON 파일로 내려받고, 이 브라우저의 최근 목록에도 넣는다.

**어디에 있는지** — 사이드바 맨 위 `프로젝트 저장 / 불러오기` 카드. `프로젝트 파일 이름` 칸과 `프로젝트 저장` 버튼이 있고, 아래에 `프로젝트 저장에는 안무표 크기, 카테고리 색상, 동작 목록, 배치 상태가 모두 포함됩니다.` 라고 적혀 있다.

**어떻게 쓰는지** — 이름을 넣고 `프로젝트 저장` 을 누르면 `<이름>-project.json` 이 내려받아진다. 이름을 비우면 `project_YYYY-MM-DD` 가 쓰인다.

**주의할 점** — 파일에 들어가는 것은 안무표 크기, 카테고리, 동작 목록, 배치, 루틴, 링크, 그리고 영상의 박자 설정(BPM · `1카운트 = N박` · 시작 지점 · 영상 주소, 영상 파일을 쓰면 그 **파일명**)이다. **영상을 한 번도 쓰지 않았다면 그 항목은 파일에 아예 들어가지 않는다** — 이 기능이 생기기 전과 파일 크기가 같다. 루틴 즐겨찾기는 루틴마다 표시가 붙어 함께 저장되지만, **들어가지 않는 것은 `기본 카운트`, 동작 · 카테고리 즐겨찾기, 정렬과 검색 설정, 되돌리기 기록, 그리고 영상의 재생 위치다.** 최근 목록은 10개까지 남고 같은 이름으로 저장하면 기존 항목을 덮어쓴다. 파일을 먼저 내려받은 뒤 목록에 넣으므로, 브라우저 저장 용량이 차면 파일은 받아졌는데 목록에는 없는 상태가 된다.

### 전체 불러오기

**무엇을 하는지** — 지금 작업을 전부 덮어쓰고 파일의 내용으로 바꾼다.

**어디에 있는지** — `프로젝트 저장 / 불러오기` 카드의 `전체 불러오기` 버튼. 최근 목록의 각 줄에도 같은 버튼이 있다.

**어떻게 쓰는지** — 버튼을 눌러 파일을 고르면 안무표 크기 · 카테고리 · 동작 목록 · 배치 · 루틴 · 링크가 모두 교체되고, 파일 이름이 이름 칸에 채워진다.

**주의할 점** — **지금의 배치 · 동작 목록 · 카테고리 · 루틴 · 링크가 전부 사라지고** 파일의 내용으로 바뀐다. `Undo` 를 누르면 링크까지 불러오기 전 상태로 함께 돌아온다. 파일 형식이 맞지 않으면 `잘못된 프로젝트 파일 형식입니다.`, JSON 으로 읽히지 않으면 `올바른 프로젝트 파일이 아닙니다.` 가 뜨고 아무것도 바뀌지 않는다. 파일에 루틴이 없으면 루틴이 전부 비워지고 루틴 즐겨찾기도 지워진다. 불러온 파일도 최근 목록에 들어간다.

### 부분 불러오기

**무엇을 하는지** — 지금 작업을 지우지 않고 다른 프로젝트의 카테고리 · 동작 · 루틴 · 배치를 겹쳐 넣는다.

**어디에 있는지** — `프로젝트 저장 / 불러오기` 카드의 `부분 불러오기` 버튼. 최근 목록의 각 줄에도 있다.

**어떻게 쓰는지** — 버튼을 눌러 파일을 고르면 병합이 끝난 뒤 `병합 완료: N개 그룹 배치됨 (M개 충돌 → 아래 레이어)` 안내가 뜬다. 겹치는 자리는 지워지지 않고 아래층으로 쌓인다.

**주의할 점** — 카테고리는 **키가 없을 때만** 더해지고 기존 색과 라벨은 그대로 둔다. 동작은 **이름이 겹치지 않는 것만** 더해진다. 루틴은 id 가 겹치지 않는 것만 들어오고, 이름이 겹치면 `이름 (2)` 처럼 번호가 붙는다. **링크는 병합되지 않는다.** 지금 안무표보다 뒤에 있는 배치는 버려지고 길이는 잘린다. 병합한 파일도 최근 목록에 들어간다.

### 최근 프로젝트 목록

**무엇을 하는지** — 이 브라우저에 남아 있는 최근 프로젝트를 다시 열거나, 이름만 가져오거나, 목록에서 지운다.

**어디에 있는지** — `프로젝트 저장 / 불러오기` 카드 아래 목록. 위에 `최근순` · `이름순` 버튼이 있고 각 줄에 파일 이름과 저장 시각, `이름 복사` · `부분 불러오기` · `전체 불러오기` · `삭제` 가 있다. 비어 있으면 `저장된 프로젝트 목록이 없습니다.` 가 뜬다.

**어떻게 쓰는지** — `최근순` · `이름순` 으로 정렬을 바꾼다. `이름 복사` 는 파일 이름을 위쪽 입력칸에 넣어 준다(`프로젝트 이름을 입력창에 복사`). `삭제` 는 2초 안에 다시 눌러(`정말요?`) 실행된다.

**주의할 점** — 이 목록은 **이 브라우저에만** 저장된다(localStorage). 다른 기기로 옮기려면 프로젝트 파일을 써야 한다. **10개까지만 남고**, 항목마다 프로젝트 전체를 품고 있어 용량이 차면 저장이 조용히 실패할 수 있다. 저장된 값이 한 글자라도 깨지면 목록 · 즐겨찾기 · 링크가 경고 없이 빈 값이 되고 다음 저장이 그 빈 값을 덮어쓴다. `삭제` 는 목록에서만 지우고 이미 내려받은 파일에는 영향이 없다. 정렬 버튼은 프로젝트 목록에만 있다.

### 동작 목록만 저장하고 열기

**무엇을 하는지** — 카테고리와 동작 목록만 따로 파일로 저장하고 다시 불러온다.

**어디에 있는지** — 사이드바 `동작 저장 / 불러오기` 카드. `동작 파일 이름` 칸, `동작 저장` · `동작 열기` 버튼, 그 아래 목록의 `불러오기` · `삭제` 가 있다.

**어떻게 쓰는지** — `동작 저장` 은 `<이름>-moves.json` 을 내려받는다(이름을 비우면 `moves_YYYY-MM-DD`). `동작 열기` 로 파일을 고르거나 아래 목록의 `불러오기` 를 누르면 적용된다.

**주의할 점** — 불러오면 **지금의 동작 목록과 카테고리가 통째로 교체된다.** 안무표의 배치는 남지만, 사라진 카테고리를 쓰던 블록은 색이 어긋난 채로 남는다. 이 목록은 3개까지만 남는다. 읽을 수 없는 파일이면 `동작 파일을 읽을 수 없습니다.` 가 뜬다.

### 카테고리만 저장하고 열기

**무엇을 하는지** — 카테고리 정의(이름과 색)만 따로 파일로 저장하고 되돌린다.

**어디에 있는지** — 사이드바 `카테고리 저장 / 불러오기` 카드. `카테고리 파일 이름` 칸, `카테고리 저장` · `카테고리 열기` 버튼, 그 아래 목록.

**어떻게 쓰는지** — `카테고리 저장` 은 `<이름>-categories.json` 을 내려받는다(비우면 `categories_YYYY-MM-DD`). `카테고리 열기` 나 목록의 `불러오기` 로 되돌린다.

**주의할 점** — 불러오면 카테고리가 전부 교체되고, **없어진 카테고리를 쓰던 동작과 배치는 첫 번째 카테고리로 강제로 옮겨진다.** 목록은 3개까지다. 읽을 수 없는 파일이면 `카테고리 파일을 읽을 수 없습니다.` 가 뜬다.

## 참고 링크 붙이기

### YouTube 링크

**무엇을 하는지** — 참고 영상 주소를 안무표 위에 붙여 두고, 영상 제목을 자동으로 가져와 칩으로 보여 준다.

**어디에 있는지** — 안무표 바로 위 링크 줄의 첫 번째 행. `▶ YouTube` 배지, `YouTube URL 입력...` 칸, `↗`(`새 창에서 열기`), `✕`(`초기화`)가 있다.

**어떻게 쓰는지** — 주소를 붙여 넣으면 잠시 뒤 `제목 불러오는 중…` 이 떴다가 제목 칩으로 바뀐다. `↗` 는 새 창에서 열고, `✕` 는 주소와 제목을 지운다. 이 칸의 주소는 [영상 패널](#영상-패널-열고-닫기)의 소스이기도 해서, 패널을 열어 둔 채 주소를 바꾸면 영상이 그 자리에서 갈아 끼워진다(패널을 새로 만들지 않으므로 화면이 깜빡이지 않는다).

**주의할 점** — 제목은 붙여 넣고 0.7초 뒤에 조회되며 **그때 함께 저장된다** — 입력 직후 새로고침하거나 탭을 닫으면 방금 넣은 주소가 통째로 사라진다. 제목 조회에는 네트워크가 필요하고, 실패하면 조용히 빈 제목이 되어 칩이 뜨지 않는다. `youtu.be/…` 와 `youtube.com/watch?v=…` 형태만 정리되고 그 밖의 주소는 넣은 그대로 열린다. 링크는 이 브라우저에 저장되는 동시에 프로젝트 파일에도 들어간다. `전체 초기화(링크 포함)` 을 누르면 함께 지워지지만 `Undo` 로 되돌아온다 — 다만 **제목은 주소보다 늦게 도착하므로**, 주소를 확정하자마자 아무것도 하지 않고 `Undo` 하면 제목이 함께 사라지고 제목만 되살릴 방법은 없다.

### ClickUp 링크와 커스텀 링크

**무엇을 하는지** — 작업 관리 링크와 임의의 참고 링크를 이름표와 함께 여러 개 붙여 둔다.

**어디에 있는지** — 링크 줄의 두 번째 행(`☑ ClickUp`, `ClickUp 태스크 URL 입력...`)과, `+ 링크 추가` 로 늘어나는 줄들(`🔗` 배지, `레이블`, `URL 입력...`).

**어떻게 쓰는지** — ClickUp 주소는 넣는 즉시 저장되고 `↗` 로 열며 `✕` 로 지운다. 커스텀 링크는 `+ 링크 추가` 로 빈 줄을 만들고 이름표와 주소를 채운 뒤 칸 밖을 클릭하면 저장된다. 줄 오른쪽 `×`(`삭제`)로 그 줄을 없앤다.

**주의할 점** — 커스텀 링크는 **칸에서 포커스가 빠질 때** 저장되므로 입력 중에는 아직 저장되지 않았다. 줄 삭제는 확인 없이 즉시 실행되지만 `Undo` 로 되살릴 수 있다. 이름표는 입력칸 안에만 보이고 링크 자체에는 나타나지 않는다. 브라우저 저장소에만 있던 오래된 링크는 구분자가 없어, 하나를 지울 때 여러 줄이 함께 사라질 수 있다. `전체 초기화(링크 포함)` 은 이 링크들도 함께 지우고, 그것도 `Undo` 로 돌아온다.

## 영상 맞춰 보기

### 영상 패널 열고 닫기

**무엇을 하는지** — 안무표 옆에 참고 영상을 띄운다. **켜야 보이는 기능**이라, 켜지 않으면 화면도 조작도 이 기능이 들어오기 전과 같다.

**어디에 있는지** — 안무표 도구 모음의 `▶ 영상 패널` 버튼(`+ 빠른 배치` 바로 오른쪽). 켜면 안무표 오른쪽에 `영상` 패널이 열리고, 헤더에 `따라가기` · `접기` · `✕ 닫기` 가 있다.

**어떻게 쓰는지** — 링크 줄의 `YouTube URL 입력...` 에 주소를 넣은 뒤 `▶ 영상 패널` 을 누른다. 영상은 그 칸의 주소를 그대로 쓰므로 패널 안에 유튜브 주소를 또 넣을 곳은 없다. `접기` 를 누르면 헤더만 남고, `✕ 닫기` 로 완전히 닫으면 안무표가 원래 폭으로 돌아온다. 재생·정지·배속은 영상 화면 안의 유튜브 조작 그대로다. 내 컴퓨터의 영상을 쓰려면 아래의 [영상 파일 열기](#영상-파일-열기)를 본다.

**주의할 점** — **외부 네트워크가 필요하다.** 유튜브의 재생 스크립트를 받아야 하므로 오프라인·사내망·광고 차단기 아래에서는 `유튜브 재생 스크립트를 불러오지 못했습니다` 가 뜨고 영상이 나오지 않는다. 퍼블리셔가 외부 재생을 막아 둔 영상은 `이 영상은 외부 재생이 막혀 있습니다` 가 뜨며, 이때는 링크 줄의 `↗` 로 유튜브에서 여는 수밖에 없다. 패널을 한 번도 열지 않으면 유튜브에 아무 요청도 나가지 않는다. 루틴 편집 패널을 열면 영상 패널이 숨고 **재생도 함께 멈춘다** — 둘 다 열면 안무표가 짜부라지기 때문이다. 창이 좁으면(1040px 이하) 패널이 안무표 위로 올라가고 처음 열 때는 접힌 채로 열린다. **재생 위치는 저장되지 않는다** — 파일에 저장되는 것은 아래의 BPM·시작 지점과 영상 주소뿐이고, 어디까지 봤는지는 새로고침하면 처음으로 돌아간다.

### 영상 파일 열기

**무엇을 하는지** — 유튜브 대신 내 컴퓨터에 있는 영상 파일(연습 촬영본 등)을 안무표 옆에 띄운다. 네트워크가 필요 없고, 카운트 점프가 유튜브보다 훨씬 정확하다(착지 오차 0.05초 안팎, 유튜브는 0.5초).

**어디에 있는지** — 영상 패널 화면 바로 아래 `📁 영상 파일 열기` 버튼. 파일을 고르면 그 자리에 파일명 칩과 `✕ 파일 놓기` 가 나타나고 버튼은 `📁 다른 파일 열기` 로 바뀐다. 헤더의 제목 칩에도 파일명이 뜬다.

**어떻게 쓰는지** — 버튼을 누르고 영상 파일을 고르면 곧바로 패널에 실린다. 재생·정지·배속·전체화면은 브라우저의 기본 영상 조작이다. 박자 맞추기·세로선·블록 켜기·배치 클릭 점프는 유튜브와 똑같이 동작한다. 파일이 열려 있는 동안은 파일이 유튜브 주소보다 우선한다 — 링크바의 주소는 그대로 남아 있고, `✕ 파일 놓기` 를 누르면 그 주소로 돌아간다(주소가 없으면 소스 없음).

**주의할 점** — **브라우저는 파일의 위치를 기억하지 못한다.** 프로젝트 파일에 저장되는 것은 파일명뿐이라, 저장한 안무표를 다시 열면 `이 안무표는 영상 파일 \`xxx.mp4\` 을 쓰던 것입니다 … 같은 파일을 다시 골라 주세요` 가 뜨고 그때 같은 파일을 다시 고르면 된다. 박자 설정은 저장되어 있으므로 다시 찍을 필요가 없다. 링크바의 `✕` 로 유튜브 주소만 지우는 것은 파일을 놓는 것이 아니다. 브라우저가 열 수 없는 형식(코덱)이면 `지원하지 않는 영상 주소입니다` 가 뜬다 — MP4(H.264) 가 가장 무난하다. 파일은 브라우저 안에서만 읽히고 어디로도 올라가지 않는다.

### 영상과 안무표의 박자 맞추기

**무엇을 하는지** — 영상의 시각과 안무표의 카운트를 이어 붙인다. 이것을 해야 재생 위치 세로선이 나타난다.

**어디에 있는지** — 영상 패널 아래쪽. 맨 위에 지금 상태(`BPM 미설정 …` 또는 `BPM 106.7 · 1카운트 = 1박 · 기준 8x1의 1카운트 = 0:01.3`)가 있고, 그 아래 세 갈래가 차례로 있다.

**어떻게 쓰는지** — 가장 정확한 것은 **두 번 찍기**다. 영상을 재생하다가 박자가 딱 떨어지는 순간에 `여기가 [8x1]의 [1] 카운트` 를 맞춰 두고 `지금 여기` 를 누른다. 한 번 누르면 안내가 `1/2 — 첫 지점 8x1의 1카운트 = 0:01.3` 으로 바뀌고 행 칸이 네 마디 뒤로 자동으로 밀린다. 한참 뒤 그 카운트가 오는 순간에 `지금 여기` 를 한 번 더 누르면 BPM 과 시작 지점이 **동시에** 정해진다. 박자만 알고 싶으면 `탭` 을 곡에 맞춰 여러 번 두드린 뒤 `탭으로 BPM 정하기` 를 누른다. 숫자를 이미 안다면 `BPM` 과 `1카운트 = N박` 에 직접 넣어도 된다(스윙은 보통 2박). 곡 중간에서 싱크가 어긋나면 그 자리를 골라 `여기로 다시 맞추기` 를 누른다 — BPM 은 그대로 두고 시작 지점만 옮긴다.

**주의할 점** — **두 지점은 멀수록 정확하다.** `8x1` 과 `8x5` 는 32카운트 차이라 클릭이 조금 늦어도 오차가 1/32 로 줄어든다. 두 지점을 거꾸로(뒤 카운트를 먼저) 찍으면 거부되고 마지막에 찍은 점부터 다시 센다. 탭은 2초 이상 벌어지면 앞의 것을 버리고 새로 세므로 중간에 손을 놓았다면 처음부터 두드린다. BPM 은 20~400 사이로 잘린다. **템포가 정해지기 전에는 재생 위치 세로선이 아예 그려지지 않는다** — 틀린 자리에 그럴듯하게 서 있는 것보다 없는 편이 낫기 때문이다. 정해진 템포는 `Undo` 로 되돌아오고 프로젝트 파일에 함께 저장된다. `템포 지우기` 는 BPM 과 시작 지점만 지우고 `1카운트 = N박` 은 남긴다.

### 재생 위치 세로선과 따라가기

**무엇을 하는지** — 영상이 재생되는 동안 지금 지점을 안무표 위에 초록 세로선으로 표시하고, 세로선이 지나가는 블록에 초록 테두리를 켜서 지금 어느 동작 차례인지 보여 주며, 그 선이 화면 밖으로 나가지 않게 안무표를 따라 스크롤한다.

**어디에 있는지** — 세로선은 안무표의 현재 행 안에 그려진다. 따라가기는 영상 패널 헤더의 `따라가기` 버튼으로 켜고 끈다(기본은 켜짐).

**어떻게 쓰는지** — 박자를 맞춰 두면 영상을 재생하는 것만으로 선이 움직이고, 선이 어느 블록 위에 있는 동안 그 블록이 초록으로 밝아진다. 다음 카운트로 넘어가 다른 블록에 들어서면 앞 블록은 꺼지고 새 블록이 켜지므로, 영상을 보면서 안무표의 동작이 순서대로 켜지는 것을 따라갈 수 있다. 같은 카운트에 여러 블록이 겹쳐 있으면(겹침 행) 전부 켜진다. `intro` 행도 시간 축에 들어 있어 곡 시작 전 구간에도 선이 선다. 손으로 안무표를 스크롤하면 3초 동안 자동 추종이 멈춰, 다른 마디를 보는 동안 화면이 끌려가지 않는다.

**주의할 점** — 세로선은 **박자를 맞춘 뒤에만** 나타난다. 재생 위치가 안무표의 마지막 행을 지나가면 그릴 자리가 없어 선이 사라진다 — 곡이 안무표보다 길다는 뜻이다. 이 선은 누를 수 없고 안무표의 다른 조작을 가리지도 않는다. 블록의 초록 테두리는 선택(노랑)·길이 조절(파랑) 표시와 겹쳐 붙을 수 있고, 블록을 누르거나 옮기는 데 아무 영향이 없다. 재생이 멈춰 있어도 선이 서 있는 자리의 블록은 켜져 있다 — "지금 위치" 표시이지 "재생 중" 표시가 아니다. 브라우저 탭을 백그라운드로 보내면 브라우저가 화면 갱신을 멈추므로 선과 블록 표시도 멈췄다가 탭으로 돌아올 때 따라잡는다.

### 배치를 눌러 그 대목 듣기

**무엇을 하는지** — 안무표의 블록을 누르면 영상이 그 블록이 시작하는 카운트로 이동해 재생된다.

**어디에 있는지** — 안무표의 블록 자체. 따로 버튼이 없다.

**어떻게 쓰는지** — 영상 패널을 열고 박자를 맞춘 상태에서 블록을 누른다. 선택 표시(`루틴으로 편성` 이 세는 그것)는 지금까지와 똑같이 함께 토글된다.

**주의할 점** — **영상 패널을 열지 않았거나 박자를 맞추지 않았으면 이 동작은 붙지 않는다** — 블록을 눌러도 지금까지와 똑같이 선택만 된다. 유튜브의 탐색은 정확하지 않아 최대 0.5초 어긋난 자리에 내려앉는다. 그래서 목표보다 두어 카운트 앞을 겨냥해 이동한 뒤 재생으로 통과시킨다 — 누른 카운트 **직전부터** 들린다. 블록의 왼쪽·오른쪽 손잡이를 잡은 것은 이동/길이 조절이므로 영상이 움직이지 않는다.

## 되돌리기와 비우기

### Undo / Redo

**무엇을 하는지** — 안무표 크기 · 배치 · 동작 목록 · 카테고리 · 루틴 · 링크 · 영상 템포를 이전 상태로 되돌리거나 다시 실행한다.

**어디에 있는지** — 안무표 도구 모음의 `Undo` · `Redo` 버튼. 되돌릴 것이 없으면 버튼이 꺼진다.

**어떻게 쓰는지** — 버튼을 누르거나 `Ctrl/Cmd+Z`(되돌리기), `Ctrl/Cmd+Y` 또는 `Ctrl/Cmd+Shift+Z`(다시 실행)를 누른다.

**주의할 점** — 기록에 담기는 것은 행 수 · 칸 수 · 배치 · 동작 목록 · 카테고리 · 루틴 · 링크 · 영상 템포(BPM·시작 지점·영상 주소) 여덟 가지다. **재생 위치는 담기지 않는다** — 되돌리기가 영상을 되감지는 않는다. **즐겨찾기 · 선택 표시 · 정렬 설정 · `기본 카운트` 는 되돌아오지 않는다.** 링크는 입력칸에서 손을 떼거나 `Enter` 를 눌러 값이 확정될 때 한 단계가 쌓인다 — 글자를 치는 동안에는 쌓이지 않고, 값이 그대로면 단계도 늘지 않는다. 기록은 100단계까지이고 새 작업을 하면 다시 실행 대기열이 비워진다. **단축키에 입력창 예외가 없다** — 이름을 고치던 중에 `Ctrl+Z` 를 누르면 글자가 아니라 안무표가 되돌아간다. 이 단축키는 루틴 편집 패널에는 가지 않는다.

### 전체 초기화(링크 포함)

**무엇을 하는지** — 안무표의 배치와 링크 줄의 내용, 그리고 영상 패널이 쓰던 영상 주소와 박자 설정을 비운다.

**어디에 있는지** — 안무표 도구 모음 오른쪽 끝의 빨간 `전체 초기화(링크 포함)` 버튼. 괄호가 무엇이 함께 지워지는지를 누르기 전에 알려 준다.

**어떻게 쓰는지** — 누르면 라벨이 `정말요?` 로 바뀐다. 2초 안에 다시 누르면 실행되고, 그냥 두면 취소되어 원래 라벨로 돌아온다.

**주의할 점** — 배치뿐 아니라 **YouTube 주소와 제목, ClickUp 주소, 커스텀 링크가 전부 지워지고** 그 상태가 이 브라우저에 곧바로 덮어써진다. 영상 패널이 열려 있었다면 **영상이 내려가고 BPM·시작 지점도 `미설정` 으로 돌아간다** — YouTube 주소를 지우면서 영상만 남겨 두면 링크 줄과 패널이 서로 다른 말을 하게 되고, 지운 주소가 다음 저장 파일에 다시 실리기 때문이다. 패널 자체는 열린 채로 남는다. **`Undo` 한 번이면 배치와 링크와 영상 설정이 함께 돌아오고**, 되돌아온 링크는 브라우저에도 다시 기록되므로 새로고침해도 남는다. 동작 목록 · 카테고리 · 루틴은 애초에 지워지지 않는다. 골라 둔 블록의 선택 표시는 지워지지 않아 `루틴으로 편성 (N)` 버튼이 남아 있을 수 있다.

## 화면과 문서

### 스크롤 잠금

**무엇을 하는지** — 모바일에서 드래그하는 동안 화면이 함께 스크롤되는 것을 막는다.

**어디에 있는지** — 화면에 늘 떠 있는 고정 버튼 둘: `사이드바`(`사이드바 스크롤 잠금`)와 `보드`(`보드 스크롤 잠금`). 잠기면 자물쇠가 🔒, 풀리면 🔓 로 바뀐다.

**어떻게 쓰는지** — `사이드바` 는 동작 목록 쪽 세로 스크롤을, `보드` 는 메인 안무표와 루틴 편집 격자의 스크롤을 함께 잠근다. 다시 누르면 풀린다.

**주의할 점** — 둘 중 하나라도 잠겨 있으면 **페이지 어디에서도 두 손가락 확대가 되지 않는다.** 잠금 상태는 저장되지 않아 새로고침하면 풀린다.

### 사이드바 높이 조절

**무엇을 하는지** — 좁은 화면에서 사이드바가 차지하는 높이를 바꾼다.

**어디에 있는지** — 사이드바와 작업 영역 사이의 가로 구분선.

**어떻게 쓰는지** — 구분선을 마우스나 손가락으로 눌러 위아래로 끈다. 끄는 동안 격자 칸 크기도 함께 다시 계산된다.

**주의할 점** — 화면 폭이 1040px 이하일 때만 듣는다. 데스크톱 폭으로 돌아가면 조절해 둔 높이가 자동으로 사라진다. 최소 높이는 60px 이다.

### 입력 후 화면 확대 되돌리기

**무엇을 하는지** — 모바일에서 입력칸을 눌렀을 때 브라우저가 키운 화면을 원래대로 되돌린다.

**어디에 있는지** — 따로 조작할 곳이 없다. 모든 입력칸과 드롭다운에서 포커스가 빠질 때 자동으로 동작한다.

**어떻게 쓰는지** — 입력이 끝나고 칸 밖을 누르면 0.1초 뒤에 배율이 돌아온다.

**주의할 점** — 이때 **스크롤이 문서 맨 위로 튄다.** 안무표 아래쪽을 보다가 이름을 고치면 화면이 꼭대기로 올라간다. 또 한 번 입력을 만지고 나면 그 뒤로는 손가락으로 확대할 수 없다.

### 문서 허브

**무엇을 하는지** — 저장소를 열지 않고 앱 안에서 이 프로젝트의 문서를 읽는다.

**어디에 있는지** — 안무표 위 도구 모음 맨 오른쪽, `전체 초기화(링크 포함)` 다음에 붙는 `문서` 버튼(`프로젝트 문서를 앱 안에서 읽는다`). 누르면 제목이 `문서`, 부제가 `저장소를 열지 않고 여기서 읽는다` 인 화면이 덮이고, 왼쪽 옆단에 `시작하기` · `기능과 사용법` · `바뀐 것` · `만드는 사람을 위해` 네 갈래로 문서가 묶여 있다.

**어떻게 쓰는지** — 옆단에서 문서를 고르면 본문이 뜨고, 읽는 절이 옆단 목차에 표시된다. 문서끼리 걸린 링크를 누르면 그 문서로 넘어간다. 문서를 여는 동안 주소에 `?doc=<문서>` 가 붙어, 그대로 새로고침하거나 링크를 넘겨주면 같은 곳이 열린다. `Esc` 나 `✕ 닫기` 로 닫는다.

**주의할 점** — **서버로 열어야 한다.** `index.html` 을 더블클릭해 `file://` 로 열면 브라우저가 ES 모듈 로딩을 막아 앱 자체가 뜨지 않는다 — 화면이 빈 채로 멈추므로 `문서` 버튼도 없다. 앱이 뜬 상태에서 문서 파일만 읽히지 않을 때는 본문 자리에 `docs/… 를 불러오지 못했다` 안내가 뜨고, 주소가 `file://` 이면 `이 페이지를 file:// 로 열었다. 문서는 서버로 열어야 읽힌다` 는 문장이 뒤에 붙는다. 저장소 폴더에서 다음을 실행하고 `http://localhost:8000` 으로 접속한다.

```
python3 -m http.server 8000
```

목록에는 등록된 문서만 나온다. 저장소에 파일을 넣어 두기만 하면 여기에서는 보이지 않는다.

## 단축키와 제스처

같은 일을 마우스와 터치로 하는 방법이 서로 다르고, 아예 한쪽에만 있는 것도 있다.

| 하려는 일 | 마우스·키보드 | 터치 |
|---|---|---|
| 동작 목록에서 안무표로 놓기 | 카드를 끌어 격자에 놓는다. 루틴 편집 격자에도 놓인다 | 카드를 0.18초 길게 눌러 칩이 뜨면 끈다. 메인 안무표에만 놓인다 |
| 길이를 그리며 놓기 | 카드를 클릭한 뒤 빈 칸을 눌러 끈다. 행을 넘겨 이어 그릴 수 있다 | 같은 방법. 다만 시작한 행 안에서만 세어 행을 넘길 수 없다 |
| `+ 빠른 배치` 로 놓기 | 클릭하거나 눌러 끈 뒤 팝업에서 고른다. 팝업이 뜨는 동안 미리보기가 남는다 | 12px 넘게 끌면 드래그, 그보다 적게 움직이면 탭으로 본다. 팝업이 뜰 때 미리보기가 지워진다 |
| 블록 옮기기 | 왼쪽 핸들을 끈다 | 왼쪽 핸들을 눌러 끈다 |
| 블록 복사하기 | `Alt`(`Option`)를 누른 채 왼쪽 핸들을 끈다 | 없다 |
| 블록 길이 조절 | 오른쪽 핸들을 끈다 | 오른쪽 핸들을 눌러 끈다 |
| 블록 지우기 | 블록을 더블클릭한다 | 같은 블록을 0.3초 안에 두 번 탭한다 |
| 블록 고르기 | 블록을 클릭한다 | 블록을 탭한다 |
| 루틴 블록 팝업 열기 | 루틴 블록을 클릭한다 | 루틴 블록을 탭한다 |
| 루틴 카드를 안무표에 놓기 | 카드를 끌어 격자에 놓는다 | 없다 |
| 동작 카드 메뉴 열기 | 이름을 우클릭하거나 더블클릭한다 | 이름을 0.48초 길게 누른다. 8px 이상 움직이면 취소된다 |
| 블록 이름 툴팁 보기 | 블록 위에 마우스를 올린다 | 왼쪽 핸들을 누르고 있는 동안 뜬다 |
| 빠른 배치 팝업에서 고르기 | `↓` `↑` 로 항목을 옮기고 `Enter` 로 확정한다 | 항목을 탭한다 |
| 빠른 배치 팝업 닫기 | `Esc` 를 누르거나 바깥을 클릭한다 | 바깥을 탭한다 |
| 고른 동작 해제 | `Esc` | 카드를 한 번 더 탭한다 |
| 되돌리기 · 다시 실행 | `Ctrl/Cmd+Z`, `Ctrl/Cmd+Y`, `Ctrl/Cmd+Shift+Z` | 도구 모음의 `Undo` · `Redo` 버튼 |
| 사이드바 높이 조절 | 구분선을 끈다 | 구분선을 눌러 끈다 |
| 스크롤 잠금 | 필요 없다 | `사이드바` · `보드` 버튼 |

마우스와 터치가 갈리는 곳은 다음과 같다.

- 터치로 그리는 배치는 **행을 넘길 수 없다.** 시작한 행 안에서만 카운트를 센다.
- `Alt` 복사와 루틴 카드 끌어다 놓기는 **터치에 없다.** 모바일에서 루틴을 안무표에 놓을 방법이 없다.
- 동작 카드의 터치 드래그는 메인 안무표에만 놓인다. 마우스 드래그는 루틴 편집 격자에도 놓인다.
- 빠른 배치 미리보기가 마우스에서는 팝업이 뜨는 동안 남고, 터치에서는 지워진다.
- 동작 카드 롱프레스(0.18초)는 손가락이 움직여도 취소되지 않는다. 이름 롱프레스(0.48초)는 8px 만 움직여도 취소된다 — 규칙이 서로 다르다.
- 터치로 그리는 동안 페이지가 함께 스크롤된다. 스크롤 잠금 버튼이 그것을 막으려고 있다.
- `Esc` 와 `Ctrl+Z` 는 언제나 메인 안무표에만 간다. 루틴 편집 패널에서는 패널 안의 버튼을 쓴다.

여기 적힌 것 중 일부는 고칠 수 있었지만 재구성 과정에서 원래 동작 그대로 두기로 한 것이다. 그 목록과 이유는 [일부러 두고 온 것](deviations.md)에 있다.
