# RM-60 null 초가 카운트 0 으로 읽히는 자리와 그 꼴의 기계 검사

`boundaryCount` 는 `Number.isFinite(Number(sec))` 로 초를 거르는데 `Number(null)`·`Number('')` 가 0 이라, 못 읽는 초가 「0초 → 카운트 0」으로 통과한다. 그래서 `splitAtPlayhead` 에 `sec: null` 이 오면 카운트 0 에서 잘린다(추론함). 이 자리를 수만 받게 고치고, 같은 꼴을 `tools/check-principles.mjs` 의 D-5 규칙이 잡게 넓힌다 — 이 꼴을 처음 짚은 것은 RM-24 다.

크기 S · 2026-11-03 에 판에서 다시 다듬었다

## 다시 다듬기 전의 설명

> src/domain/tempo.js 의 boundaryCount 는 Number.isFinite(Number(sec)) 로 초를 거르는데 Number(null) 은 0 이라 null 이 「0초」로 통과한다(추론함 — 지금 호출부 둘이 null 을 넘기는지는 재지 않았다). 이 꼴을 check-principles 의 D-5 규칙으로 잡으려면 이 자리를 고치거나 예외 이유를 달아야 한다.

## 요구

- `boundaryCount` 는 null · undefined · 빈 글 · 수가 아닌 값을 읽을 수 없는 초로 보고 null 을 돌려준다 — 0 은 지금처럼 0초로 읽는다
- 호출부 둘(`boardCommands` 의 `playheadBoundary` → `splitAtPlayhead`, `captureCommands` 의 `driftPatch`)이 null 초로 카운트 0 경계를 만들지 않는다 — 고치기 전에 붉음을 재현해 확인한다
- `node tools/check-principles.mjs` 의 D-5 규칙이 `Number.isFinite(Number(x))` · `isFinite(Number(x))` 꼴(null 이 0 으로 통과)도 잡고, 고치는 법을 찍는다
- 고친 뒤 저장소 전체에서 D-5 걸림이 0 이고, 원칙 문서 D-5 의 「기계가 잰다」와 버그 기록이 새 꼴을 말한다

## 결정 사항

- 새 꼴을 D-5 에 넣을까, 다른 번호로 따로 둘까
  - D-5 에 넣는다 — 「0 이 뜻을 갖는 자리에서 Number 변환이 값을 바꾼다」는 같은 뿌리라 원칙 목록 · 규칙 이름표 시험(`RULES.map` 아홉)이 그대로다. 예외 표식도 `원칙-예외(D-5)` 하나로 같다
  - 새 번호(D-n)로 따로 둔다 — 규칙 이름표 시험 · CLAUDE.md · PRINCIPLES.md 머리의 원칙 목록 세 곳을 함께 고친다. 걸린 자리에서 원칙 이름이 더 정확하게 보인다
  - **고른 답**: D-5 에 넣는다
- boundaryCount 가 숫자 글(예: '4.5')을 계속 받아 줄까
  - 수만 받는다 — 호출부 둘이 모두 수를 넘기므로 동작은 바뀌지 않고, null · 빈 글 · 숫자 글을 한꺼번에 막는다. 검사기 규칙의 고치는 법도 이 꼴 한 가지가 된다
  - 숫자 글은 받고 null · 빈 글만 막는다 — `sec != null && sec !== '' && Number.isFinite(Number(sec))` 꼴이 된다. 바깥 입력이 글로 올 길이 생겨도 견디지만, 거름이 길어지고 규칙의 고치는 법이 두 갈래로 갈린다
  - **고른 답**: 수만 받는다

## 조심할 것

- `splitAtPlayhead` 가 null 초로 0 에서 자르는 것은 아직 추론이다 — 새 시험이 고치기 전에 붉지 않으면 그 갈래는 지우고, `boundaryCount` 단위 결함만 고쳤다고 보고한다
- RM-24 가 PRINCIPLES.md D-5 에 같은 꼴의 글을 더했다고 적혀 있다(지금 main 의 D-5 본문에는 아직 없다 — RM-24 브랜치나 커밋 안 한 변경에 있을 수 있다). 두 쪽이 같은 절을 고치므로 병합할 때 글을 합친다
- 정규식이 `Number.isFinite(Number(a) + b)` 처럼 Number 가 식의 일부인 꼴까지 잡으면 걸림이 너무 많아진다 — `isFinite(` 바로 안쪽이 `Number(…)` 하나로 닫히는 꼴만 잡도록 `matchBrace` 로 잰다
- `blankJs` 가 주석 · 글을 비우므로 tempo.js 의 ⚠ 주석 속 설명은 걸리지 않는다 — 시험에 주석 속 예문이 0건인지도 넣는다
