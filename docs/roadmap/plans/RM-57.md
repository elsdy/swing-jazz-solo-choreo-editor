# RM-57 블록 몸통 끌기가 잡은 칸을 지키지 않음

블록 몸통의 k번째 칸을 잡고 끌어 놓으면, 놓은 칸이 아니라 놓은 칸에서 k를 뺀 자리가 블록의 시작이 되게 고친다. 마우스(boardGesture 의 bodyMove · bodyUp)와 손가락 길게 누르기(touchDrag 의 moveGhost · finish)가 모두 hit.col 을 그대로 써서, 마디 중간을 잡고 곧게 옮겨도 블록이 밀리고 다음 마디로 넘쳐 둘로 갈린다. 손가락 묶음 끌기를 만드는 RM-48 과 touchDrag 를 함께 고치니, 먼저 병합되는 쪽이 오프셋을 그대로 물려줘야 한다.

크기 M · 2026-11-03 에 판에서 다시 다듬었다

## 다시 다듬기 전의 설명

> RM-12 마무리 확인(2026-11-03)에서 잼: 블록 몸통의 k번째 칸을 잡고 끌어 놓으면 시작 칸이 놓은 칸 − k 가 아니라 놓은 칸(손가락·마우스 아래 칸)이 된다. 8카운트 블록 3·5번째 칸을 잡고 바로 위 빈 행으로 곧게 옮기면 시작 0→2·0→4 로 밀려 다음 마디로 넘쳐 둘로 갈린다. 손가락(0.4초 길게 누르기)·마우스 모두 8판 중 8판 재현, 0번 칸을 잡으면 지켜진다. 원인: src/input/touchDrag.js finish 와 src/domain/boardGesture.js 몸통 뗌(bodyUp)·미리보기가 targetStartIndex 에 hit.col 을 그대로 쓰고 잡은 칸 오프셋을 빼지 않는다 — 옛 왼쪽 이동 손잡이는 늘 0번 칸을 잡아 드러나지 않았다. RM-12 커밋 본문의 「잡은 자리 지킴」과 어긋난다. 고침: 누를 때 잡은 칸(누른 x − 블록 왼쪽)/칸폭을 세션에 담고 놓는 칸·미리보기에서 뺀다(0 아래로는 자르기). 회귀 시험: 몸통 3번째 칸을 잡고 위 행으로 옮기면 시작 칸이 그대로인지.

## 요구

- 마우스로 몸통을 끌어 놓으면 블록의 시작이 (놓은 칸 − 누를 때 잡은 칸 오프셋)이 된다 — 옮기기 · Alt 복사 · 묶음 옮기기 모두
- 마우스로 끄는 동안의 미리보기도 놓일 자리와 같은 시작 칸에 그린다(미리보기 = 결과)
- 손가락으로 0.4초 길게 눌러 끌어 놓으면 같은 규칙으로 시작 칸이 정해지고, 미리보기도 그 자리에 그린다
- 잡은 칸 오프셋은 블록 시작에서 잰 선형 칸 수다 — 여러 행에 걸친 블록의 둘째 조각을 잡아도 맞아야 하고, 0번 칸을 잡으면 지금과 같다
- 놓을 시작이 보드 첫 칸보다 앞이면 첫 칸으로 자른다
- 회귀 시험: 8카운트 블록의 3번째 칸을 잡고 바로 위 빈 행으로 곧게 옮기면 시작 칸이 그대로다

## 결정 사항

- 놓을 시작이 놓은 행의 0번 칸보다 앞으로 가면 어디에 둘까 — 항목 설명은 「0 아래로는 자르기」라 했지만, 여러 행에 걸친 블록의 둘째 조각을 잡으면 오프셋이 8을 넘어 늘 0번 칸으로 잘린다
  - 가. 선형으로 빼서 앞 행으로 넘어가게 두고, 보드 첫 칸에서만 자른다 — 어느 칸을 잡든 곧게 옮기면 시작이 그대로 지켜진다. 다만 행 0번 칸 가까이 놓으면 블록이 앞 행 끝에서 시작한다
  - 나. 놓은 행 안에서만 빼고 0번 칸으로 자른다(설명대로) — 블록이 늘 손가락이 있는 행에서 시작한다. 하지만 여러 행 블록의 둘째 조각을 잡거나 행 앞쪽에 놓으면 잡은 자리가 지켜지지 않는다
  - **고른 답**: 가. 선형으로 빼서 앞 행으로 넘어가게 두고, 보드 첫 칸에서만 자른다

## 조심할 것

- RM-48(손가락 묶음 끌기)이 touchDrag 의 start · finish 를 고친다 — 먼저 병합되는 쪽의 오프셋 빼기를 다른 쪽이 덮지 않게 다시 받아 본다
- 블록 요소의 rect 는 그 행의 조각만 덮는다 — rect.left 를 칸 폭으로 나누는 대신 누른 칸의 선형 위치 − 블록 시작으로 재야 여러 행 블록에서 틀리지 않는다
- 도메인 계층은 DOM 을 몰라야 한다 — 오프셋은 입력 계층이 재어 값으로 넘기고, boardGesture · gestureMath 는 수만 다룬다(check-arch)
- 골든(placement-algorithms)은 moveGroup 의 targetStartIndex 를 그대로 받으니 바뀌지 않아야 한다 — 바뀌면 손댄 자리가 틀린 것이다
