# RM-68 포장 README 의 아직 재지 못한 것 갱신

RM-28 마무리(2026-11-03)에 LGPL ffmpeg 7.1.1 을 지어 실은 .dmg 를 이 맥과 mac-mini(macOS 27.2)에서 쟀고, 윈도우 setup.exe 의 깔기 · 켜기 · 저장 · 다시 깔기도 API 로 쟀다. 그런데 packaging/README.md 의 「아직 재지 못한 것」과 ffmpeg 대본 설명, ROADMAP.md 의 RM-28 줄은 아직 그 전 모습이라 잰 것과 남은 것(윈도우 자르기 h264_mf · 두 OS 의 첫 실행 경고 화면)으로 다시 쓴다. 판의 RM-67(튜토리얼 맥 첫 실행 안내)과 같은 사실(맥 첫 실행은 「그래도 열기」)을 다루므로 README 의 서명 절은 RM-67 과 말을 맞춘다.

## 다시 다듬기 전의 설명

> RM-28 마무리(2026-11-03)에서 ffmpeg-lgpl-mac.sh 를 돌려 LGPL 7.1.1 을 지었고(링크는 /System · /usr/lib 뿐, h264_videotoolbox) --ffmpeg 로 .dmg 를 다시 지어 이 맥 · 다른 맥(mac-mini M6 · macOS 27.2)에서 자르기 HTTP 201 을 쟀다. 윈도우(WSL 노드 → 윈도우 파이썬 3.13.17 · Inno Setup 6.7.3 · Korean.isl)에서 setup.exe 를 지어 깔기 · 켜기 · 영상 · 저장 · 같은 포트 · 둘째 실행 · 지우고 다시 깔기를 API 로 쟀다.
