# RM-36 폰의 `+ 빠른 배치` 가 켜짐을 보이게 한다

폰 폭에서는 엄지 줄의 `+ 빠른 배치` 만 보이는데, 이 버튼은 켜짐 값을 받지 않고 늘 흐린 모양(ghost)으로 그려진다. 그래서 눌러도 토글로 보이지 않는다. 엄지 줄도 메인 판의 켜짐 값을 읽어 캔버스 바와 같은 활성 모양(quick-btn-active)을 입게 한다. 다시 그리는 길(render.js 의 toolbar · 보드 갱신 → 엄지 줄 다시 그리기)은 이미 있으므로 값과 모양만 잇는다.

크기 S · 2026-10-13 에 판에서 다시 다듬었다

## 다시 다듬기 전의 설명

> 폰 폭에서는 캔버스 바의 「+ 빠른 배치」가 숨고 엄지 줄의 같은 버튼만 보이는데, 엄지 줄은 이 버튼을 늘 흐린 모양으로 그리고 켜졌는지를 받지도 않는다. 그래서 눌러 켜도 하이라이트가 안 되어 토글로 보이지 않는다. 엄지 줄이 켜짐을 읽어 캔버스 바와 같은 활성 모양을 입게 한다.

## 요구

- 엄지 줄의 상태 함수가 메인 판의 빠른 배치 켜짐을 넘긴다
- 빠른 배치가 켜지면 엄지 줄 버튼이 캔버스 바와 같은 활성 모양(quick-btn-active)을 입고, 꺼지면 흐린 모양으로 돌아간다
- 켜짐을 보조 기술에도 알린다(aria-pressed)
- 다시 그려도 버튼이 갈아 끼워지지 않아 누름이 허공에 떨어지지 않는다

## 순서

- thumbBar.js 의 getState 타입에 quickPlaceOn?: boolean 을 더하고, plan 의 quick 칸이 그 값으로 cls 를 quick-btn-active / ghost 중 하나로 고르게 한다. 글자는 domContract 의 CLS.quickBtnActive 를 써서 toolbarView 와 같은 이름을 따른다(ui 끼리 import 는 domContract 만 예외로 허용된다)
- ThumbAction 에 pressed?: boolean 을 더하고, render 에서 pressed 가 있으면 aria-pressed 를 싣고 없으면 지운다
- main.js 의 views.thumb = createThumbBar({ getState }) 에 quickPlaceOn: !!store.get().session.quickPlaceMode[BOARD_MAIN] 을 더한다. render.js 는 이미 d.toolbar 와 보드 갱신 때 엄지 줄을 다시 그리므로 손대지 않는다
- tests/unit/thumbBar.test.mjs 를 새로 쓴다 — elements 로 가짜 thumbBar(children · appendChild · ownerDocument.createElement · body.dataset)를 넘겨 켜짐 · aria-pressed · 엘리먼트 재사용을 잰다. 돌리는 것은 node --test tests/unit/thumbBar.test.mjs 하나
- node tools/check-arch.mjs 로 ui → domContract import 가 허용되는지 확인한다
- FEATURES.md 의 엄지 줄 칸에 「켜면 캔버스 바처럼 초록으로 바뀐다」를 적고 HISTORY.md 에 한 줄을 남긴다. 라벨은 바꾸지 않으므로 TUTORIAL 은 그대로 둔다

## 확인 시나리오

병합 뒤 눈으로 볼 사람 확인 줄이 생기면 브라우저 노드가 main 커밋의 임시 보드(예시 판 — 프로젝트 {pid}, 이 항목은 {item})에서 이 걸음을 따라 하며 영상을 찍는다(B667). 할 것: open(열기) · click(누르기) · type(적기) · wait(기다리기) · see(보임 확인).

| 걸음 | 할 것 | 대상 | 값 | 기대 |
|---|---|---|---|---|
| 1 | open | #/p/{pid} | — | 폰 폭(≤1040)에서 안무표가 열리고 화면 아래에 엄지 줄이 보인다 |
| 2 | see | #thumbBar button[data-act="quick"] | + 빠른 배치 | 엄지 줄에 `+ 빠른 배치` 가 흐린 모양으로 있다 |
| 3 | click | #thumbBar button[data-act="quick"] | — | 빠른 배치가 켜진다 |
| 4 | see | #thumbBar button[data-act="quick"].quick-btn-active | + 빠른 배치 | 버튼이 초록 활성 모양이 되고 aria-pressed 가 true 다 |
| 5 | click | #thumbBar button[data-act="quick"] | — | 빠른 배치가 꺼진다 |
| 6 | see | #thumbBar button[data-act="quick"].ghost | + 빠른 배치 | 버튼이 흐린 모양으로 돌아간다 |

## 조심할 것

- main.js 의 getState 에서 store 를 읽는 길이 store.get().session 인지 store.session 인지 그 자리의 쓰임을 보고 맞춘다 — toolbarView 는 store.session.quickPlaceMode 를 읽는다
- 엄지 줄은 ≤1040 폭과 영상 띠의 docked 줄 양쪽에서 같은 뷰다. quick 칸은 영상이 닫힌 상태에만 있으므로 docked 줄에는 영향이 없지만, .thumb-bar button 의 CSS 가 .quick-btn-active 의 !important 배경을 가리지 않는지 폰 폭에서 눈으로 본다
- 엄지 줄의 render 는 버튼마다 className 을 덮어쓰므로, aria-pressed 를 토글 칸이 아닌 버튼에 남기지 않게 지우는 분기를 둔다
- RM-17(디자인 토큰)이 먼저 병합되면 활성 색의 이름이 바뀔 수 있다 — 클래스 이름을 domContract 에서 가져오면 따라간다
