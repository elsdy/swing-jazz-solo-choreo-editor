# RM-55 기본 테마 띠의 차례 줄 단추가 패널 밖으로 밀림

기본 테마(basic)에서는 `<html>` 에 data-theme 이 붙지 않는다. 그런데도 drawFlowTrack 이 길 SVG 를 넣고 단추에 인라인 left/top 을 달아서, 기준(position:relative · overflow:hidden)을 잃은 ①②③ 단추가 패널 오른 끝 밖으로 밀리고 nav 높이가 그릴 때마다 커진다. 이 일은 기본 테마에서는 길을 그리지 않고 단추 자리를 화살표 줄로 되돌린다. 테마를 켜고 끌 때도 다시 그려 맞춘다. RM-58(테마 쪽 길 단추가 띠 아래로 떨어짐)과 drawFlowTrack · index.html 의 차례 줄 CSS 가 겹친다. 그래도 RM-58 이 만들 코드를 부르지는 않으므로 선행으로 두지 않는다.

크기 S · 2026-11-03 에 판에서 다시 다듬었다

|---|---|---|---|---|

| 2 | click | text=영상 | — | 영상 패널이 띠 모드로 열린다 |
| 3 | see | #videoFlowSteps | — | ①②③ 단추가 화살표로 이어진 한 줄로 패널 안에 서고, 오른쪽으로 넘치지 않는다 |
| 4 | see | #videoFlowSteps .flow-track | — | 기본 테마에서는 길 SVG 가 보이지 않는다 |
| 5 | click | #videoFlowSteps .flow-step | — | 단계를 눌러도 줄 높이가 커지지 않는다 |

## 조심할 것

- RM-58 이 같은 drawFlowTrack 과 index.html 의 테마 길 CSS 를 고친다 — 이 일은 테마가 없을 때의 갈래와 테마 밖 규칙만 더하고 :root[data-theme] 규칙의 자리 값은 건드리지 않는다. 먼저 병합된 쪽에 맞춰 다시 받는다
- 테마 함수의 실제 이름은 main.js 1930 줄 근처에서 확인해 적는다 — applyTheme 이 아니면 손댈 파일의 이름을 고친다
- 인라인 left/top 을 비우는 것을 잊으면 CSS 로 SVG 만 숨겨도 단추가 밀린 채 남는다(인라인이 CSS 를 이긴다) — JS 갈래가 핵심이다
- 테마를 바꾸는 순간 차례 줄을 다시 그리지 않으면 candy → basic 에서 옛 좌표가 남는다
- 렌더마다 getBoundingClientRect 를 재는 비용이 기본 테마에서는 필요 없다 — 테마 확인을 재기 앞에 둔다
