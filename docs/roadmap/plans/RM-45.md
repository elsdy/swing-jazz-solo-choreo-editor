# RM-45 인쇄 격자 너비가 화면 칸 너비를 따른다

인쇄할 때 칸 너비가 화면에서 잰 --cellW(px)를 그대로 따라가서, 좁은 화면에서는 격자가 A4의 45~60%만 쓰고 2560 화면에서는 7·8카운트가 종이 밖으로 잘린다. 인쇄에서는 칸 너비를 화면 폭과 상관없이 종이 너비(@page A4 여백을 뺀 폭)에서 행 라벨 · 비고 · 틈을 빼고 칸 수로 나눈 값으로 다시 정해, RM-21 요구 1(A4 너비에 맞춘다)을 되살린다. RM-46(Safari 행 잘림)·RM-47(비고 열 불일치)과 같은 @media print 블록을 고치지만, 서로의 코드를 부르지는 않는다.

크기 S · 2026-11-03 에 판에서 다시 다듬었다

## 다시 다듬기 전의 설명

> RM-21 요구 1(A4 너비에 맞춘다)이 깨진다. 칸 너비가 JS 가 화면에 맞춰 html 인라인에 쓴 --cellW(px)라 인쇄에서도 그대로다 — 폰 폭 390(37~44px)이나 영상 패널로 판이 좁으면 격자가 A4 의 45~60%만 쓰고, 2560 화면(168px)이면 7·8카운트(Safari 는 비고도)가 종이 밖으로 잘린다. Chrome · WebKit 둘 다 재현. 고침 후보: @media print 에서 :root 의 --cellW 를 !important 로 종이 너비 기준(calc((100vw - 행 라벨 - 틈)/칸 수) 등)으로 덮거나 beforeprint/afterprint 에서 다시 잰다.

## 요구

- 인쇄하면 격자(행 라벨 + 카운트 칸 + 비고 열)가 화면 폭(390 · 1280 · 2560)이나 영상 패널을 열었는지와 상관없이 같은 종이 너비를 꽉 채운다
- 인쇄에서 어떤 카운트 칸도(7·8카운트 · 비고 포함) 종이 밖으로 잘리지 않는다
- 인쇄 창을 닫고 화면으로 돌아오면 칸 너비 · 블록 자리가 인쇄 전과 같다(화면용 --cellW 를 고치지 않는다)
- 칸 수(cols)가 8이 아닌 안무표에서도 같은 식으로 맞는다

- 원칙 U-16 예외 표식 줄에 이유가 이 규칙까지 덮는지 보고, 필요하면 이유를 고친다

## 결정 사항

- 인쇄 종이를 A4로 못박을까 — 지금은 브라우저 인쇄 설정(Letter 등)을 따른다
  - @page 로 A4 · 여백 10mm 를 못박는다 — 칸 너비 식이 190mm 라는 정해진 값을 써서 Chrome · Safari가 똑같이 찍는다. 사용자가 Letter를 골라도 A4 꼴로 찍힌다
  - 종이는 브라우저에 맡기고 100vw 로 계산한다 — Letter · A3도 따라가지만, WebKit은 인쇄 미디어를 화면 폭으로 재므로(RM-47에서 본 것) 100vw가 화면 폭이 되어 Safari에서는 그대로 깨질 수 있다
  - **고른 답**: @page 로 A4 · 여백 10mm 를 못박는다
- 비고 열이 넓으면(--noteW 최대 280px 남짓) 인쇄에서 칸이 좁아진다 — 인쇄 비고 폭을 줄일까
  - 인쇄에서는 비고 열을 종이의 25% 안으로 줄인다 — 카운트 칸이 늘 읽을 만한 너비를 지킨다. 긴 비고는 줄을 바꿔 행이 높아진다
  - 화면에서 잰 비고 폭을 그대로 쓴다 — 고칠 것이 적지만, 비고가 길면 8칸이 종이의 절반 남짓으로 눌린다. 비고를 아예 뺄지는 RM-47이 정한다
  - **고른 답**: 인쇄에서는 비고 열을 종이의 25% 안으로 줄인다

## 조심할 것

- --cellW 를 :root 에서 !important 로 덮으면 화면으로 돌아온 뒤에도 남을 수 있고, JS 인라인 값과 무게 싸움이 난다 — .board-wrap 에 새 값을 두어 상속만 끊는 쪽으로 간다
- Safari는 인쇄에서도 미디어 폭을 화면으로 재므로 vw를 쓰는 식은 깨진다 — mm로 정한 종이 폭을 쓴다(추론함, 실제 WebKit 인쇄로 확인해야 한다)
- 블록 자리 · 너비는 calc(n × var(--cellW))라 상속을 끊으면 따라오지만, 재생 막대(playhead)는 px를 캐시한다 — 인쇄에서는 숨기거나 영향이 없는지 본다
- RM-46(.board 를 display:block 으로)·RM-47(비고 숨김)이 같은 @media print 블록과 .board 틈 값을 고친다 — 틈 4px · --noteCol 값이 바뀌면 식이 어긋나므로, 시험이 블록에서 값을 읽게 해 둔다
- 루틴 편집 보드는 인쇄에서 숨겨지지만, --cols 를 그 보드에도 적으면 메인 보드와 섞이지 않는지 본다
