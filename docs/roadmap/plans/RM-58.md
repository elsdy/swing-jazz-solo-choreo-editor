# RM-58 테마의 흐름 길 단추가 영상 패널 본문 위에 뜬다

테마를 켠 영상 띠에서 흐름 길 단추(마디와 이름)가 길 띠(.flow-steps, 104px) 아래로 떨어져 ③ 받아 적기 칸의 단추와 말로 이름 줄을 덮는다. 이 일은 먼저 실제 화면에서 그대로 재현해 원인을 잰 뒤 고친다. 좌표는 domain/flowTrack 이 띠 높이 안에 들도록 보장하고, ui/videoPanel 의 drawFlowTrack 은 띠 크기가 바뀌면 다시 그리게 한다. 같은 차례 줄이 기본 테마에서 패널 밖으로 밀리는 RM-55 와 자리(index.html 의 band CSS · videoPanel 의 차례 줄)가 겹치지만, RM-55 가 만들 코드를 부르지는 않으므로 선행으로 두지 않는다.

크기 S · 2026-11-03 에 판에서 다시 다듬었다

## 다시 다듬기 전의 설명

## 요구

- 테마를 켠 영상 띠(1440x779 창 · 영상 패널 열림)에서 흐름 길 단추의 마디와 이름이 길 띠 상자 안에 머물고, 그 아래 ③ 받아 적기 칸의 단추와 말로 이름 줄을 덮지 않는다
- 길의 마디 좌표는 마디 반지름과 그 아래 이름 높이를 더해도 띠 높이를 넘지 않는다 — domain/flowTrack 이 이를 보장하고, 띠가 너무 낮으면 활을 낮춰 맞춘다
- 창 크기가 바뀌거나 테마를 켜고 끄거나 띠가 처음 자리를 잡을 때 길과 단추 좌표를 다시 재어 그린다 — 처음 잰 높이에 묶여 어긋나지 않는다
- 기본 테마(테마 없음)의 화살표 줄 차례 단추는 이번 고침으로 모양 · 자리가 바뀌지 않는다

## 순서

- 재현: python3 server.py 로 띄우고 1440x779 · 테마 켬 · 영상 패널 열림에서 .flow-steps 와 .flow-step 들의 상자, drawFlowTrack 이 잰 rect.height, 단추의 left/top 인라인 값, 계산된 position · overflow 를 잰다. 단추가 띠 아래로 넘치는지 확인하고, 띠가 자리 잡기 전에 잰 높이인지 · 마디와 이름이 띠 높이를 넘는 좌표인지 · 다른 규
- domain.test.mjs 에 [RM-58 요구 1] 시험을 먼저 써서 지금 좌표가 붉은지 본다
- flowTrack 에 마디 반지름 · 이름 높이 여백 인자를 더해 점의 y 를 띠 안으로 넣고, 낮은 띠에서는 활을 낮춘다. 복잡도 표지를 다시 잰다
- drawFlowTrack 이 그 여백을 넘기고, 원인이 잰 때의 문제면 flowSteps 에 ResizeObserver 를 달아(테마 · 창 · 띠가 바뀔 때) 다시 그린다. 복잡도 표지를 고친다
- 필요하면 index.html 의 테마 .flow-steps 높이와 .flow-name 자리를 domain 이 쓰는 수와 맞춘다. 좌표는 여전히 한 곳(domain)에서만 정한다
- videoPanelMarkup.test.mjs 에 CSS 높이와 flowTrack 이 맞는지 보는 [RM-58 요구 1] 시험을 더하고, domain · markup 시험만 돌린다
- 브라우저에서 재현을 다시 돌려 단추가 띠 안에 드는 것과 기본 테마의 화살표 줄이 그대로인 것을 확인한다
- 버그 기록(증상 · 원인 · 수정 · 재발 방지)과 이력을 적는다

## 결정 사항

- 띠가 마디와 이름을 다 담지 못할 때 무엇을 줄일까 — 길 띠 높이(104px)를 지킬지
  - 띠 높이 104px 를 지키고 길의 활을 낮춘다 — 아래 ③ 받아 적기 칸과 안무표 자리는 그대로다. 대신 낮은 띠에서는 길이 덜 휘어 그림의 맛이 조금 줄어든다
  - 띠를 마디와 이름에 맞춰 키운다 — 길의 활은 그대로 살지만, 영상 띠가 그만큼 길어져 779px 창에서 안무표의 몫이 줄어든다(BOARD_MIN_H 와 부딪칠 수 있다)
  - **고른 답**: 띠 높이 104px 를 지키고 길의 활을 낮춘다

## 조심할 것

- 원인은 아직 추론이다 — overflow:hidden 인 띠 밖으로 단추가 보인다는 관찰은 지금 CSS 와 맞지 않는다. 그래서 재현으로 잰 값이 계획과 다르면 손댈 자리가 index.html 의 band CSS 쪽(body[data-videoband] .flow-steps 와 :root[data-theme] .flow-steps 가 겨루는 자리)으로 옮겨 갈 수 있다
- 테마 길은 「테마는 모양을 바꾸지 않는다」의 하나뿐인 예외로 두기로 사람이 정했다(DECISIONS 2026-11-02) — 길을 걷어 내는 쪽으로 고치지 않는다
- RM-55(기본 테마 차례 줄 밀림)와 index.html 의 band CSS · videoPanel 의 차례 줄이 겹친다 — 기본 테마 규칙을 건드리면 RM-55 와 충돌하니 :root[data-theme] 아래 규칙만 고친다
- ResizeObserver 콜백에서 다시 그리면 다시 배치되고, 그것이 다시 콜백을 부를 수 있다 — 단추는 절대 배치라 띠 크기를 바꾸지 않아야 하고, 크기가 같으면 그리지 않는다
- 단추를 갈아 끼우지 않는다는 규약(누르는 순간 사라지면 클릭이 떨어진다)을 지킨다 — 다시 그릴 때는 좌표만 고친다
