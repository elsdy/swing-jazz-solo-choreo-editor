## 결정 사항

- 시험 수를 어디에 두나 — README 와 개발 지침(CLAUDE.md)의 두 자리가 어긋나 있다(622 대 648)
  - 개발 지침 한 자리에만 두고 README · ARCHITECTURE 는 숫자 없이 가리킨다 — 고칠 자리가 하나라 다시 어긋날 일이 없고, 검사가 다른 문서에 숫자가 새로 끼는 것을 막는다. README 를 보는 사람은 한 번 더 눌러야 수를 본다
  - 두 자리에 다 두고 검사가 두 수가 같은지 맞춰 본다 — README 에서도 수가 바로 보인다. 다만 수를 바꾸는 PR 마다 두 줄을 고쳐야 하고, 둘 다 같이 틀리면 검사가 못 잡는다
  - README 만 이번에 맞추고 검사는 두지 않는다 — 가장 작은 일이지만 다음에 시험 수를 바꾸는 PR 에서 또 묵는다 — 이 항목이 생긴 까닭 그대로다
  - **고른 답**: 개발 지침 한 자리에만 두고 README · ARCHITECTURE 는 숫자 없이 가리킨다
